# The promises the tests keep: one row is one thing the toolkit promises, and the test file that guards it.
#
# Format = <what keeps the promise> | <the test file> | <the promise, in one sentence>   (paths from the repository root)
# Checked by scripts/check/contracts.py (run by `task ci`): every test file under tests/ and preview/tests/ is in a
# row, and every row names a target and a test file that exist.
#
# A new test file comes with its row. A promise is said in what can be seen from outside: what a deck looks like,
# what is refused, what a command prints or writes. Before removing a test, look for the red it has seen
# (tests/mutants/ and the history); a test that stopped a real defect keeps its row.
#
# Slow tests (Actions, PR #197, the ten slowest): test_line_breaks.py 3.84 s (every name of the corpus is built),
# test_mutant_tables.py 1.59 s (the example table is run end to end). Every other test call is under 1 s.
