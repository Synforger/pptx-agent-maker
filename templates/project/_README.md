# <project>

デッキ 1 案件の置き場。**道具はここに入らない** (= 道具は `pptx-agent-maker`、ここは案件の
ものだけ)。道具がこの folder を見つける口は `workspace.toml` 1 枚。

```
<project>/
├── workspace.toml     この設定 (= 予約名)
├── specimen.pptx      意匠の元 (= 予約名。複製されて各頁の器になる。雛形が 1 枚持っている)
├── w1.toml            ← 何を並べるか
├── w1.pptx            ← それを焼いたもの
├── w2.toml
├── w2.pptx
└── assets/
    ├── w1/            マニフェストと同じ名前の folder が、その回の素材
    └── w2/
```

**焼いたデッキと、それを組んだマニフェストが対で並ぶ。**開いて確かめるのは焼いたほうなので、
それがマニフェストの隣に在るのがいちばん短い。回を folder で仕切ると、1 回ぶんを見るのに
2 階層降りることになる。素材だけは数が多いので回ごとに分ける。

## 始め方

```bash
python3 -m pptx_agent_maker init <案件のフォルダ>
python3 -m pptx_agent_maker build <案件のフォルダ> example
```

**写した直後に 1 本焼ける。**同梱の `example.toml` と、それが要る型見本と絵が入っている。

## 意匠は 2 か所で揃える

同梱の `specimen.pptx` は**道具の既定の意匠**で焼いた見本 (= どこの会社のものでもない)。
案件の意匠にするときは、2 か所を揃える:

1. **`specimen.pptx` を案件のものに差し替える** ― 複製する頁 (= 表紙) と、焼いたデッキを
   PowerPoint で開いて手で頁を足したときの見た目は、これが決める
2. **`workspace.toml` の `[theme]` に書体と色を書く** ― 型で組んだ頁はこれが決める

⚠ **片方だけ変えると、複製した頁と型で組んだ頁が違う顔になる。**

版面の割り方 (= 余白・級数・間隔) は案件から動かせない。同じ役割の頁が回をまたいで
同じ形であることのほうを取る。

## 決まり

- **道具側に案件の語を持ち込まない。**版面の語彙 (= 帯・カード・図・表) は道具が持ち、
  何をどう並べるかはここが持つ
- **`*.pptx` は焼き直せるもの**。消えて困るものを置かない (= `specimen.pptx` だけが別)
- **道具の見本を案件の意匠で上書きしてよい** (= 雛形が持つのは出発点であって、正解ではない)
- **回の名前がそのまま素材の folder 名** (= w1 のマニフェストは assets の下の w1 を見る)。
  マニフェストに `assets` と書けば変えられる
