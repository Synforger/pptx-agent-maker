# <project>

デッキ 1 案件の置き場。**道具はここに入らない** (= 道具は `pptx-agent-maker`、ここは案件のもの
だけ)。道具がこの folder を見つける口は `workspace.toml` 1 枚。

| folder | 中身 |
|---|---|
| `base/` | この案件の型見本デッキ (= 複製して使う実物) |
| `manifests/` | デッキ 1 本につき 1 枚。どの頁を何の順で並べるか |
| `pages/` | この案件だけの頁 (= 結果の一覧のように、並べ方が案件に固有のもの) |
| `assets/` | 絵と素材 |
| `output/` | 焼いたデッキ |

## 始め方

```bash
python3 -m pptx_agent_maker.project init <案件のフォルダ>
```

## 決まり

- **道具側に案件の語を持ち込まない。**版面の語彙 (= 帯・カード・図・表) は道具が持ち、
  何をどう並べるかはここが持つ
- **`output/` は焼き直せるもの**。消えて困るものを置かない
- `base/` の型見本を増やすのは、**同じ頁を 2 回使ったことが分かってから**
