# 参照

## 案件を建てる

```bash
pptx-agent-maker init <案件のフォルダ> --specimen <テンプレート.pptx or それを置いた folder>
```

⚠ **見た目は建てるときに決める** (= あとから `specimen.pptx` を手で置き換えると、
忘れた回だけ顔が変わる)。folder を渡すと `specimen.pptx` と隣の `workspace.toml`
(= 色の表) を一緒に持ってくる。

## manifest

```toml
specimen = "specimen.pptx"     # 予約名。案件の見た目
out = "w1.pptx"                # マニフェストの隣に焼かれる
assets = "w1"                  # 省略すると、この file の名前が素材の folder 名

[[pages]]
kind = "copy"                  # テンプレートの N 頁目を複製して文言を差し替える
page = 1
replace = [["旧", "新"]]

[[pages]]
kind = "import"                # 前のデッキの N 頁目を、手を入れたまま持ってくる
deck = "w0.pptx"
page = 12
pictures = ["a.png", "b.png"]  # 頁の絵を並び順 (= 上の段から、同じ段は左から) で入れ替える
tables = [[["手法", "値"], ["A", "1"]]]  # 表の中身を並び順で入れ替える (= 行と列の数は元と同じ)

[[pages]]
kind = "declare"               # 型で組む
type = "figure"
title = "…"
```

⚠ **`why` は 1 行の覚え書き** (= 200 字、日付を書くと拒まれる)。改訂の履歴は git log が持つ。

## recipe (= `recipes.toml`)

```toml
[recipes.result]                # 名前は英数字・-・_
type = "figures"                # 必須
title = "{method} の結果"        # {穴} は呼ぶ頁の fill で埋める
footer = "採点表から"
```

頁は `kind = "recipe"` / `recipe = "<名前>"` / `fill = { ... }` と、recipe に無いキーだけを書く。
拒まれるもの = recipe が決めたキーの書き換え / 埋め残した穴 / 使わない fill / 無い recipe 名。

上げる: `task promote -- <名前> w1:5 w2:7` (= 2 頁以上、同じ型の `declare` だけ)。

## 会社のテンプレートへ上げる (= `lift`)

```bash
pptx-agent-maker lift <案件> <テンプレートの folder> \
    [--recipe <名前>]... [--page <deck>:<頁>]... \
    [--keep "<そのまま残す文言>"]... [--replace "<案件の語>=<差し替え前提の語>"]...
```

テンプレートの folder = `specimen.pptx` + `workspace.toml` (+ `recipes.toml` + `example.toml`)。頁は
`specimen.pptx` の末尾へ、recipe は `recipes.toml` へ。`init --specimen <folder>` が、在る物を全部配る。
`example.toml` はその見本に合わせた見本の宣言 (= 表紙の置き字を全部差し替え、`stale_words` に当たる文を
載せない)。置かなければ道具付属の物が配られ、置き字や検査の語が違う見本では、建てた直後の 1 本が検査で止まる。
文言は `--keep` / `--replace` で扱った物のほか、全部 `<文言 N>` になる (= recipe の文言も同じ。
型の名前は除く)。拒まれるもの = 当たらない `--replace` / グラフや埋め込み file を持つ頁 /
テンプレートに既に在る recipe 名。

## 型 (= 本体に何を置くか)

| 型 | 要るもの | この型だけが読むもの | 本体 |
|---|---|---|---|
| `figure` | `figure` | `caption` | 絵を 1 枚、縦横比のまま最大で |
| `figures` | `figures` | ― | 絵を横に並べる (= 説明は絵ごとに `["a.png", "説明"]`) |
| `figure_grid` | `figures` | `columns` | 絵を格子に並べる |
| `flow` | `stages` | `align_rows` `direction` | 段を左から右へ、あいだに → (= `direction = "down"` で上から下へ、段の中は横に並んで分岐) |
| `roadmap` | `stages` | `align_rows` | 到達点までの段を矢羽根で左から右へ。各段の下にノード (= 省ける) |
| `compose` | `rows` (= 格子なら `grid` と `cells`) | `backdrops` | 本体を段とマスで書く (= 行や列をまたぐ箱が要る頁は、格子に置く)。マスに部品を 1 つ (= 上の型も入る。他の箱を中に持つ枠は `panel`)。図が無くても通る |
| `timeline` | `periods` `lanes` | `phases` `milestones` `links` | 期間を左から右、レーンを上から下。レーンの中に棒と印。棒に `id` を付けて `links` で棒どうしを矢印でつなげる |
| `chart` | `chart` | ― | 数字から描くグラフを 1 つ (= 棒・縦棒・折れ線・積み上げ・滝グラフ。PowerPoint で数字を直せる) |
| `cards` | ― | ― | 札だけの頁 (= 図が要らない骨格) |
| `board` | `table` | ― | 表が主役の頁 (= 同上) |
| `agenda` | `buckets` | `highlight` `highlight_tone` `numbers` `look` `highlight_item` `list_marks` | 章立て (= 同上。`highlight` = 強調する章の番号。`highlight_tone = "accent"` でその章の箱を地の色で強調し (= 書かなければ `◀ この章` の言葉)、`numbers = "circled"` で番号を丸の数字にする。`look = "cards"` は、右に「アジェンダ」 の見出しと、列の高さを章の数で等分した角丸のカードを置き、番号を塗りの丸にする (= 章の名前を `名前 ― 要旨` と書くと、要旨がカードの 2 行目に入る。`highlight_tone` と `numbers` は書けない)。`highlight_item` は `cards` の時だけ、今の章の小項目を 1 つ差し色の太字にする (= 章の途中から入り直す頁)。`list_marks = "numbers"` は `cards` の時だけ、左の一覧の印を番号にする (= 章は右の丸と同じ「1」、小項目は章ごとに「(1)」から、下の段は印なし。書かなければ `•` と `–`)。小項目は `["名前", ["下の段", …]]` と書くと、その下にもう 1 段並ぶ (= 章 → 中の段 → 頁の名前。下の段が出るのは `highlight` の章だけで、章を名指さなければ全部の章。`highlight_item` は小項目の番号で数える)) |

### 箱・棒・矢羽根の見た目 (= どれも同じ 4 つのキー)

カード・flow と道のりのノード・`compose` のカード・線表の棒・道のりの段は、どれも同じ 4 つを同じ意味で読む
(= `compose` の入れ物 `panel` は、このうち `icon` を除く 3 つを読む):

| キー | 意味 | 見た目 |
|---|---|---|
| `tone` | 地の色の役 (= 道具の 6 つか、`[theme.grounds]` の名前) | 地の色。字の色と枠は地から決まる |
| `icon` | 名前の前に置く絵 (= `assets/` の PNG など) | 箱は左上に正方形、棒と矢羽根は名前の前に字の高さで |
| `tentative = true` | 在れば / 内容未定 | 紙の色の地に、灰色の点線の枠と灰色の字 |
| `strong = true` | クリティカルパス、目を集めたい 1 つ | 地はそのままで、本文の色の太い枠 (= 点線と一緒なら太い点線) |

- 線表の棒の `tone` は、書かなければレーンの色。道のりの段の `tone` は、書かなければ薄い地 (= 到達点は濃い地)
- **線表の棒の塗り方は `[theme] bar_look`** (= 下の「見た目」)。`outlined` の資料では、色を運ぶ `tone` の棒は
  カードと同じく、地がごく薄い色で枠が色になる
- ⚠ **強調は絞る** (= 1 頁に 1 本の道筋か 1 つの箱。全部を強調すると何も目立たない)
- 棒にアイコンを付けると名前の使える幅が減るので、短い棒では名前が隣へ出ることがある。アイコンも入らない短さなら止まる

### `flow` の書き方

```toml
[[pages]]
kind = "declare"
type = "flow"
title = "…"
align_rows = true                                      # 任意。同じ順番のノードを横に揃える
# direction = "down"                                   # 任意。段を上から下へ (= 既定は "right"、左から右)

[[pages.stages]]
name = "Intake"                                        # 段の名前
nodes = [
  ["Triage", "sort by impact"],                        # [見出し, 本文]
  { heading = "No owner", body = "the request waits", tone = "bad" },   # 色の役を付ける書き方
  { heading = "Device", body = "reads the tag", icon = "device.png" },   # アイコンを置く書き方
]
settled = "one queue"                                  # 任意。段の下に置く 1 行
```

- **ノードは 2 通りに書ける** ― `["見出し", "本文"]` か、`{ heading = …, body = …, tone = …, icon = … }`
  (= `body` と `tone` と `icon` は省ける)。**カードも同じ 2 通りで書ける**
- **`icon` は箱の左上に置く絵** (= 素材は図と同じく `assets/` から。文字はその右に寄る)。縦横比は
  保ったまま 1 辺 1.2cm の正方形に収まる。読めるのは PNG / JPEG などの絵で、⚠ **SVG は拒まれる**
  (= 表示する大きさの数倍で PNG に書き出す)。濃い地の箱には明るい色の絵を使う。アイコンは頁の図には
  数えない (= 図の要る頁が、アイコンだけで通ることは無い)
- **`tone` は色の役** ― `box` (= 既定) / `band` / `tint` / `accent` / `good` / `bad`、または案件が
  `[theme.grounds]` で名前を付けた地 (= 下の「見た目」)。色そのものは `[theme.palette]` と `[theme.grounds]` が持つ。⚠ **`good` / `bad` は読み (= 良い / 悪い) を示す物にだけ使う**
  (= 飾りで塗ると、色が意味を持たなくなる)
- **薄い地 (= `box` / `band` / `tint`) の箱は、その地を濃くした色の細い枠を持つ** (= 紙の上で端が
  読める。カードの箱も、線表の棒も同じ)。濃い地の箱に枠は無い。枠の色は地から出るので書かない
- **`direction = "down"` は、段を上から下へ並べる** ― 段の中のノードは**横に並ぶ** (= 1 つなら段の幅
  いっぱい、2 つ以上なら等分。そこが横への分岐になり、次の段が 1 つなら合流)。段の名前は左に立ち、段と段の
  間に `↓` が入る。`settled` はその段のノードの下。収まらなければ止まる (= 段を減らすか 2 頁に分ける)。
  `align_rows` は一緒に書けない (= 横に並ぶノードは、はじめから同じ高さ)
- **`align_rows = true`** は、行が意味を持つ頁のため (= 上から 1 番目は誰、2 番目は誰)。
  行の高さはその行で一番高いノードに揃う。書かなければ、ノードは段ごとに自分の高さで積まれる
- ノードの高さは中の文字が実際に折れる行数で決まる (= 書体ごとに測った字幅で数える)
- **文字の大きさ** ― 段の名前 14pt、ノードの見出し 16pt、**本文と `settled` は 12pt**。10pt は
  出所と絵の下の説明だけに使う (= 頁の中身には使わない)

### `roadmap` の書き方

```toml
[[pages]]
kind = "declare"
type = "roadmap"
title = "…"
align_rows = true                                      # 任意。flow と同じ

[[pages.stages]]
name = "Early Nov | 0.4.0"                             # 矢羽根の中の名前 (= 時期と版)
nodes = [
  ["Core", "reads every input"],                       # flow のノードと同じ書き方
  { heading = "Docs", body = "how to start", tone = "tint", icon = "docs.png" },
]

[[pages.stages]]
name = "Dec | 0.5"                                     # nodes は省ける。矢羽根だけの段になる
weight = 2                                             # 任意。段の幅の比 (= 書かなければ 1)

[[pages.stages]]
name = "Jan | 1.0"
goal = true                                            # 任意。最後の段だけ。到達点として強調する
nodes = [ ["Release", "anyone can install it"] ]
```

- **段は左から右へ矢羽根で並ぶ** ― 最初の段は左が平ら、2 段目からは左が切り欠かれ、前の段の先が
  そこへ入る。向きは矢羽根が示すので、段の間に → は置かない
- **`goal = true` は最後の段だけ** (= ほかの段に書くと拒まれる)。到達点の矢羽根は濃い地で、名前が
  一回り大きい (= 16pt。ほかの段は 14pt)。ほかの段の矢羽根は薄い地に枠
- 段のキーは `name` / `nodes` / `goal` / `weight` と、見た目の 4 つ (= `tone` / `icon` / `tentative` / `strong`)。
  flow の `settled` は読まない。段は 2 つ以上
- **`nodes` は省ける** (= `nodes = []` と同じ)。省いた段は矢羽根だけで、その下は空く。**全部の段で省けば、
  矢羽根の帯だけが立つ** (= 帯の高さだけを使う)。一部の段だけ省くと、
  書いた段のノードだけが積まれ、`align_rows` も書いた段の間で揃う。`box_height = "page"` の資料でも、
  矢羽根は伸びず、ノードが残りの高さを分け合う。**`flow` は省けない** (= 段に中身が要る型)
- **`weight` は段の幅の比** (= 0 より大きい数。書かなければ 1 で、全部の段が書かなければ等分)。
  一部の段だけ書いてもよい (= `weight = 2` の段は、書かない段の 2 倍の幅)。矢羽根の先が次の段の
  切り欠きに入る作りは、幅が違っても変わらない。段の下のノードは自分の段の幅で折り返し、高さも
  その幅で数える (= 細い段のノードは行が増えて背が高くなる)。`flow` の段は `weight` を読まない (= 等分のまま)
- 長い名前は矢羽根の中で折れ、全部の矢羽根がいちばん高い名前に揃う
- 収まらない頁は縮めずに止まる (= ノードを短くするか、段を 2 頁に分ける)

### `compose` の書き方 (= どの型にも無い組み方)

```toml
[[pages]]
kind = "declare"
type = "compose"
title = "目標と、それを支える 2 本の柱"

[[pages.rows]]                                         # 1 段目: 横幅いっぱいに 1 枚
[[pages.rows.cells]]
card = { heading = "目標", body = "…", tone = "accent" }

[[pages.rows]]                                         # 2 段目: 2 枚を横に
[[pages.rows.cells]]
card = { heading = "0.4.0", body = "…", icon = "core.png" }
[[pages.rows.cells]]
weight = 2                                             # 任意。幅の比 (= 既定 1)
[pages.rows.cells.timeline]                            # 型を 1 マスに丸ごと入れる (= その型の書き方のまま)
periods = ["Nov", "Dec", "Jan"]
[[pages.rows.cells.timeline.lanes]]
name = "Core"
bars = [ { from = 0, to = 2, text = "build" } ]
```

- **段は上から下、マスは左から右**。マスの幅は `weight` の比。マスには部品を 1 つだけ置く:
  `card` (= ノードと同じ 2 通りの書き方) / `figure` (+ `caption`) / `table` / `text` (= 本文の色と大きさの文章) /
  `points` / `chart` (= 下の「`chart` の書き方」のまま) / `voices` (= 下の「人の声」) / `panel` (= 下の「入れ物」) /
  並べ方 (= `ring` `tree` `overlap`、下の「並べ方」) / 型 (= `flow` `roadmap` `timeline` `figures` `figure_grid` `board` `agenda`)。
  マスに `rows` を書けば入れ子になる。マスに `part` を書けば案件の部品を呼ぶ (= SKILL の「同じ形のマスは部品にする」)
- **高さ** ― カード・表・文章・要点だけの段は**中身の言葉ぶんの高さ**で、同じ段のカードは一番高い物に揃う。
  絵や型の入った段と、段に `weight` を書いた段は、**残りの高さを `weight` の比で分け合う**。分け合う段に置いた
  カードや文章は自分の高さのまま上に寄る (= 段がそれより低ければ止まる。段の `weight` を増やすか、物を減らす)。
  マスの絵は横幅いっぱいで上に寄り、縦が足りなければ縮む。**空の文章 (`text = ""`) のマスは高さを取らない**
  (= 段の高さは同じ段のほかのマスで決まり、段の全部が空なら 0。何も描かず、矢印が横切れる空きになる)
- **間** ― 同じ段のマスとマスの間は使い方の `gap_x`、段と段の間は `gap_y` (= 書かなければどちらも `gap_m`)。
  横の間だけ広げて縦は詰める頁は、使い方の `[theme.uses.<名前>.spacing]` に `gap_x` と `gap_y` を書く。入れ物 (`panel`)
  の中の段とマスも同じ 2 つ。題・帯と本体の間は `band_gap` (下の「資料の使い方」の表)
- **格子 (`grid`)** ― 1 つの箱が複数の行や列をまたぐ頁 (= 部門をまたぐ流れ図のように、帯と、帯をまたぐ箱) は、段とマスでは
  書けない。`rows` の代わりに `grid` と `cells` で書く (= `rows` と `grid` は同じ頁に書けない。止まる。今までの `rows` の
  書き方は変わらない)。`grid` と `links` は、最初の `[[pages.cells]]` より上に書く:

  ```toml
  [[pages]]
  kind = "declare"
  type = "compose"
  title = "利用者と開発者が出会う所"
  grid = { columns = [1.6, 3, 3, 3], rows = [1, 1] }      # 列と行の比 (= `weight` と同じ読み方)
  links = [ { from = "device", to = "build" }, { from = "build", to = "use" } ]

  [[pages.backdrops]]                                      # 帯の地 (= マスより下の層に敷く)
  at = [1, 1]                                              # [行, 列] (= 1 から)
  span = [1, 4]                                            # [行の数, 列の数] (= 書かなければ [1, 1])
  tone = "内部向け"
  [[pages.backdrops]]
  at = [2, 1]
  span = [1, 4]
  tone = "外部向け"

  [[pages.cells]]                                          # 帯の名前は、背景の上の普通の文字のマス
  at = [1, 1]
  text = "利用者"
  role = "label"
  [[pages.cells]]
  at = [2, 1]
  text = "開発者"
  role = "label"
  [[pages.cells]]
  at = [1, 2]
  span = [2, 1]                                            # 2 行をまたぐ箱
  id = "device"
  card = { heading = "入力の機器", body = "…" }
  [[pages.cells]]
  at = [2, 3]
  id = "build"
  card = { heading = "実装", body = "…" }
  [[pages.cells]]
  at = [1, 4]
  id = "use"
  card = { heading = "利用", body = "…" }
  [[pages.cells]]
  at = [1, 3]
  legend = true                                            # 色ごとの意味 (= 下の「意味の名前を付けた地」)
  ```

  - **列と行は本体を比で分け合う** (= 間は列と列が `gap_x`、行と行が `gap_y`)。`columns` と `rows` は、それぞれ比の並び
  - **マス** `[[pages.cells]]` は、`at = [行, 列]` と `span = [行の数, 列の数]` が格子のどこを覆うか。中に置ける物と書き方は
    段のマスと同じ (= `weight` だけは書けない。幅と高さは `grid` の比で決まる)。**マスどうしが重なる時と、格子の外へ出る
    `at` `span` は、どのマスかを言って止まる**
  - **マスの中身は、覆う範囲の四方から同じ幅だけ内側に置く** (= 箱・文字・表・凡例のどれも。幅は使い方の `gap_m` の半分)。
    隣り合う箱の間は、その幅の 2 つ分と列や行の間になる (= 矢印が読める長さが残る)。**箱 (= カードと入れ物) はそこを
    使い切り、文章・表・要点は自分の高さのまま上に寄る**。行をまたぐ箱は、またぐどの行の箱とも向き合うので、矢印が
    真っすぐ引ける。中身が自分の高さ (= 字の分) を超える時は、段のマスと同じ文で止まる (= 縮めない。`grid` の `rows` の
    比を増やすか、物を減らす)
  - **背景** `[[pages.backdrops]]` は `at` `span` `tone` (= カードの `tone` と同じ名前。書かなければ薄い地の `band`)。覆う範囲
    (= 間も含む) いっぱいの地を、マスより下の層に敷く (= 内側へは寄せない。箱は上の決めで、背景の縁から内側に立つ)。
    背景どうしが重なる時は止まる。**背景と箱の重なりは、検査も重なりと数えない** (= 入れ物の地と同じ。文字どうしの
    重なりは今までどおり検査する)
  - 帯の名前の専用の部品は無い。背景の上の `text` のマスに書く (= 色が濃い背景の上なら、その地で読める `tone` を文章に書く)
  - `links` は格子のマスの `id` でも引ける (= 下の「マスどうしの線」)。段 (`rows`) の頁と同じ決まり
- 座標は書けない (= 割るだけなので、はみ出しも重なりも起きない)。大きさと色は今までどおり決まっている
- **文章の役 (`role`)** ― `text` のマスにだけ書ける。書かなければ本文の色と大きさ:
  - `role = "display"` ― 頁の主役の数字を**特大** (= 書かなければ題の 2 倍。`[theme.type]` の `display` で決められる。
    差し色の太字) で置く。数字の意味は下か隣の
    マスに本文で書く (= 「98%」だけでは何の数か読めない)
  - `role = "label"` ― 列や行の**見出し**。`stage` の大きさの太字 (= 本文の色)。カードの上に並べる列見出しや、
    図の上の小見出しに使う
  - `role = "note"` ― 添える**小さい字**。`caption` の大きさの灰 (= 図表の読み方、出典の補足、1 行の注)
  - `role = "mono"` ― コード・コマンド・数式の行を**等幅** (= Consolas) で、書いたとおりの行と字下げのまま、
    薄い地の枠に置く。⚠ **折らない** ― いちばん長い行がマスに入らなければ止まる (= 行を短くするか、
    マスの `weight` を増やす)
- **文章の色と寄せ (`tone` `align`)** ― `display` `label` `note` と、役を書かない文章に書ける (= `mono` と、
  文章でないマスには書けない。止まる):
  - `tone` ― 字の色の役 (= カードの `tone` と同じ名前)。`accent` `good` `bad` と、案件が `[theme.grounds]` で
    濃い色に名前を付けた地は**その色の字**。意味を持たない薄い地 (= `box` `band` `tint`、薄い地に名前を付けた物)
    は、紙の上の字にすると読めないので**本文の色のまま**。書かなければ、役ごとの色 (= `display` は差し色、`note` は
    灰、ほかは本文の色)
  - `align` ― `"left"` (= 既定) か `"center"` (= カードの `align` と同じ)

  ```toml
  [[pages.rows.cells]]
  text = "98%"
  role = "display"

  [[pages.rows.cells]]
  text = "手法 A"
  role = "label"
  tone = "accent"
  align = "center"

  [[pages.rows.cells]]
  text = "10 回の平均 (= 出所は下)"
  role = "note"

  [[pages.rows.cells]]
  text = """
  def area(r):
      return 3.14 * r * r"""
  role = "mono"
  ```
- 型をマスに入れた時に読むのは、その型のキーだけ (= カード・表・文章は隣のマスに置く)
- 収まらない頁は、どの段のどのマスかを言って止まる (= 縮めない)
- 図が無くても通る (= カードだけの頁も組める)。⚠ だからといって文章だけの頁を作らない
- **並べ方** ― 箱どうしの並びそのものが意味を持つ時に使う。どれも座標は書かず、箱の数と中身から位置が決まる。
  箱は `card` と同じ 2 通りの書き方 (= 色の役・アイコン・点線・強調も同じ)。収まらなければ縮めずに止まる
  - **輪 (`ring`)** ― 回り続ける段 (= 計画 → 実行 → 評価 → 改善)。箱 3〜8 つをマスいっぱいの楕円の上に、
    上から時計回りに置き、隣どうしを矢印でつなぐ (= 最後の箱から最初の箱へも)。箱はぶつからない一番大きい
    幅になる。マスの残りの高さを使う (= 段に `weight` を書いて広げる)

    ```toml
    [[pages.rows.cells]]
    ring = [ ["計画", "目標と手順を決める"], ["実行", "小さく試す"], ["評価", "数字で確かめる"],
             { heading = "改善", body = "次の計画に返す", tone = "accent" } ]
    ```
  - **木 (`tree`)** ― 親と子 (= 組織、分類、課題の分解)。根から下へ段に分け (= 根を含めて 4 段まで)、子は
    親の下に並び、親から子へ線が引かれる。葉の数でマスの幅を割るので、葉が多いと箱が細くなり、見出しの
    いちばん長い語が入らなければ止まる。高さは段ごとの中身の言葉ぶん

    ```toml
    [[pages.rows.cells]]
    [pages.rows.cells.tree]
    heading = "社長"
    children = [
      { heading = "営業部", children = [ { heading = "東日本" }, { heading = "西日本" } ] },
      { heading = "開発部" },
    ]
    ```
  - **重なり (`overlap`)** ― 2 つか 3 つの集まりと、その共通部分 (= ベン図)。円を透かして重ね (= 重なった所が
    濃く見える)、それぞれの名前は自分だけの所に、`shared` は全部が重なる所に置く。集まりは `"名前"` か
    `{ name = "…", tone = "…" }` (= 色の役は書かなければ `box` / `band` / `tint` の順)。名前と共通の言葉は短く
    (= 円の一部に入らなければ止まる)

    ```toml
    [[pages.rows.cells]]
    overlap = { sets = ["技術", "事業", "デザイン"], shared = "革新" }
    ```
  - **絵の上の印 (`marks`)** ― `figure` のマスに書き、写真や図の 1 点を指して名前を付ける (= 製品の各部、画面の
    各所)。`at` は絵の上の位置を**絵に対する割合**で書く (= `[横, 縦]`、左上が `[0, 0]`、右下が `[1, 1]`。頁の座標では
    ないので、絵の外へは出ない)。名前は、点が絵の左半分なら左の列、右半分なら右の列に、点の高さに合わせて並び
    (= 重なれば下へずれる)、名前から点まで細い線が引かれ、点には小さな印が付く。列の幅はいちばん長い名前の
    1 行ぶん (= マスの 3 分の 1 まで)。名前が列の高さに収まらなければ止まる

    ```toml
    [[pages.rows.cells]]
    figure = "camera.png"
    marks = [
      { at = [0.25, 0.30], text = "レンズ" },
      { at = [0.80, 0.55], text = "シャッター" },
    ]
    ```
  - **絵の高さの線 (`guides`)** ― `figure` のマスに書き、置いた絵を上から測った割合の所に、**絵の幅いっぱいの横の線**を
    引く (= 絵のどの高さを読むかを、絵の上に示す)。`guides` は 0 より大きく 1 より小さい数のリスト、`guide_tone` は線の色の役
    (= カードの `tone` と同じ名前。書かなければ `accent`。薄い地の役は本文の色のまま)。線は細い線の太さ。名 (`caption`)
    を付けても、測るのは絵だけ。範囲の外の数、空のリスト、`guides` の無い `guide_tone` は理由つきで止まる。
    ⚠ `marks` とは一緒に書けない (= 絵の横の名前と絵の上の線は、同じ高さを読む 2 通りの書き方)

    ```toml
    [[pages.rows.cells]]
    figure = "profile.png"
    guides = [0.2, 0.5, 0.8]
    guide_tone = "bad"
    ```
  - **絵を置く縦の位置 (`valign`)** ― 絵がマスより低い時 (= 横に長い絵を、縦に余るマスへ置いた時) の位置。`"top"`
    (= 既定。上端に付く)・`"middle"`・`"bottom"`。名を付けた絵は、名と一緒に動く。絵が縦に詰められてマスの高さを
    使い切る時は動く先が無い。`marks` を付けた絵には書けない (= 名の列が絵の位置を決める)
  - **絵の左右の内側の余白 (`inset`)** ― 絵の左と右に同じだけ取る余白 (= cm。書かなければ 0 で、絵はマスの
    横幅いっぱい)。マスの幅と隣のマスとの間は変えずに、絵だけを細くする (= 元の頁の写真が、マスの両脇を少し
    空けて置かれている時)。絵は形を保つので、細くした分だけ低くなる。`marks` を付けた絵には書けない
  - **マスどうしの線 (`links`)** ― マスに `id` を付け、頁の `links` に「どこからどこへ」を書くと、2 つのマスの
    向き合う所に矢印が引かれる (= 横に並ぶマスは横の矢印、上下のマスは縦の矢印)。
    **向き合う 2 つ** (= 縦か横の範囲が重なる) は真っすぐな矢印で結び、**向き合わない 2 つ** (= 斜め。帯の違う箱など) は、
    **直角に 1 回曲がる線**で結ぶ。曲がる線は、出る側と入る側を、元の箱から相手へ近い方の辺から選ぶ (= 横の隙間が縦の
    隙間より狭いか等しければ、元の箱の左右の辺から横へ出て、相手の上か下の辺へ縦に入る。そうでなければ、元の箱の上下の辺
    から縦に出て、相手の左右の辺へ横に入る)。PowerPoint の曲がるコネクタ 1 つで書くので、人が箱を動かしても、折れ目と
    両端は離れない。**線がほかの箱を横切る時は止まる** (= どの線がどの箱を横切るかを言う。箱の並びを直す。逆の折れ方には
    自動で替えない)。曲がる線には `text` を書けない。知らない `id` も止まる。段 (`rows`) の頁でも、格子の頁でも同じに効く。
    `links` は最初の `[[pages.rows]]` (= 格子の頁は `[[pages.cells]]`) より上に書く。1 本ごとに 2 つを足せる:
    - `tone` ― **矢印の色の役** (= カードの `tone` と同じ名前。線も矢じりもその色)。書かなければ灰
    - `text` ― **矢印のそばに置く言葉**。置き場は矢印の向きで決まり (= **上下へ向かう矢印なら右、左右へ向かう矢印なら上**)、本文の大きさの太字・本文の色で置く
      (= 矢印の色 `tone` とは別。線が橙でも言葉は濃い色)。言葉は矢印の隙間 (= 段と段、マスとマスの間) に折って
      入る。⚠ **隙間に入らなければ縮めずに止まる** ― 縦の矢印は隙間の高さ (= 本文の 1 行より低い既定の間隔には
      1 行も入らない)、横の矢印は隙間の幅と、向き合う 2 つのマスの高さの半分に入れる。言葉が入る頁は、使い方の
      `[theme.uses.<名前>.spacing]` の `gap_m` (= 横の矢印なら `gap_x`、縦の矢印なら `gap_y`) を広げる。縦の矢印の言葉は、
      右に別のマスがあればその手前で止まる
    - **空のマス (`text = ""`) は矢印が横切れる** (= 中身の在るマスは今どおり止まる)。離れた 2 つのマスを、間の
      空きをまたいで長い矢印で結べて、言葉は空きの上にも広がる

    ```toml
    [[pages]]
    kind = "declare"
    type = "compose"
    title = "受付から返答まで"
    links = [ { from = "in", to = "sort" }, { from = "in", to = "log", text = "全件", tone = "accent" } ]

    [[pages.rows]]
    [[pages.rows.cells]]
    id = "in"
    card = { heading = "受付", body = "窓口で受ける" }
    [[pages.rows.cells]]
    id = "sort"
    card = { heading = "仕分け", body = "担当を決める" }

    [[pages.rows]]
    [[pages.rows.cells]]
    id = "log"
    card = { heading = "記録", body = "全件を残す" }
    ```
- **入れ物 (`panel`)** ― 他の箱を中に持つ枠。マスに `panel = { … }` を書き、中身は `rows` に**頁の段とマスと同じ書き方**で
  書く (= 中に `card` `text` `points` `table` `chart` 絵 と、入れ子の `panel` も置ける。中の割り方は頁の段とマスと同じで、
  別の並べ方はない)。キーは次のとおり (= `rows` のほかは省ける):
  - `rows` ― 中の段とマス (= 必須。1 段は要る)
  - `tone` ― 箱の色の役 (= カードの `tone` と同じ名前。書かなければ `box`)。入れ物だけは、`tone = "paper"` で**白い地**
    (= 紙の色そのもの。枠は薄い地の枠と同じ細い灰の線) も選べる (= カードと棒は選べない)。字は本文の色で読めるので、
    中へ字を直に置ける。`tentative = true` と `strong = true` もカードと同じ意味で書ける (= `icon` は読まない)
  - `heading` ― 枠の中の**左上**に置く見出し。大きさはカードの見出し (= `heading` の大きさ) の太字で、色もカードの
    見出しと同じ決まり。長ければ折れ、中の段はその下から始まる
  - `rule = true` ― 見出しの下に**細い線** (= 見出しの色。太さは細い線)。見出しが無ければ止まる

  見た目は資料の `card_look` に従う。**`filled` (= 既定)** の資料では、`tone` の地を塗る。**`outlined`** の資料では、色を
  運ぶ役 (= `accent` `good` `bad`、濃い `[theme.grounds]`) の箱は、色をごく薄く混ぜた地に**色の枠と見出し**、角は丸い
  (= カードと同じ。中の字は本文の色)。中の余白は使い方の `pad` で、中の段と段の間は `gap_y`、マスとマスの間は `gap_x`。

  ```toml
  [[pages.rows.cells]]
  id = "seen"                                    # 入れ物そのものも `links` の端にできる
  [pages.rows.cells.panel]
  tone = "accent"
  heading = "見えたこと"
  rule = true
  rows = [
    { cells = [ { text = "92%", role = "display" } ] },
    { cells = [ { card = { heading = "読み", body = "…" } }, { card = { heading = "次の手", body = "…" } } ] },
  ]
  ```

  - **高さ** ― 見出しと中の段の高さの合計 (= 中の段は頁の段と同じ数え方)。同じ段の入れ物は一番高い物に揃う。中に絵や
    型の段が在る入れ物と `weight` を書いた段は、残りの高さを取る。段が入れ物より低ければ、縮めずに止まる。
    `box_height = "page"` の資料では、入れ物はカードと同じに**置かれたマスの高さを使い切り**、中のカードは入れ物の
    中の高さを使う (= 中の段のうち、カードを持つ段が余りを等しく受ける)。入れ物が受ける高さは、同じ物を頁の段に直に
    置いた時と同じで、中の段はそこから余白 2 つ分と見出しを引いた残りを割る。中で足りずに止まった時は、外の段が
    取っている高さも言う (= 動かせるのは、上や下の段を短くするか、頁を分けるか)
  - **入れ物と並ぶカード** ― 同じ段に入れ物が在れば、カードの字は入れ物の見出しと同じ上端から置く (= `outlined` の資料
    でも縦の中央に置かない。見出しどうしが同じ高さに並ぶ。札は 1 行なので中央のまま)
  - **`links`** ― 入れ物の**内と外をまたいで**書ける (= 中のマスと外のマスの間にも矢印を引く。矢印は描かれた箱どうしで引かれ、
    入れ物そのものに `id` を付ければ入れ物が端になる)。間に別のマスや入れ物が立てば止まる。入れ物と、その中身の間は
    結べない
  - ⚠ **濃い地の入れ物の中へ、字を直に置かない** ― `filled` の資料で、`accent` `good` `bad` や濃い `[theme.grounds]` の入れ物は
    地が濃く、字は紙の色で置かれる。中へ直に置く `text` `points` `table` `chart` `voices` と並べ方、名や印の付いた絵は
    本文の色なので読めず、止まる。**`card`・入れ物・コードの枠・名の無い絵は置ける**。字を置くなら、薄い地の `tone` にするか、
    カードに入れるか、資料の `card_look` を `outlined` にする (= そちらでは色は枠と見出しが持つので、何でも置ける)

- **人の声 (`voices`)** ― アンケートの自由記述や来場者の感想を、言い換えずに「人が言った言葉」として並べる。
  1 つずつ吹き出し (= 尾の付いた角丸の枠。1 つの図形) に入り、誰の声かが尾の下に小さく出る。見出しは持たない
  (= カードで置くと、短い声にも見出しの行が付いて高くなり、数の札と見分けが付かない)

  ```toml
  [[pages.rows.cells]]
  voices = [
    { text = "「展示が分かりやすかった」", who = "作品 A" },   # who は任意
    { text = "「次は家族で来たい」", who = "作品 B", tone = "tint" },   # tone は任意 (= 箱と同じ語彙。既定は box)
  ]
  ```

  1 行に並ぶ数はマスの幅で決まり (= 1 つの声に 10 字ほど入る幅が下限)、行どうしで数を均す (= 6 つなら 3 つずつ)。
  同じ行の吹き出しは一番高い物に揃う。高さは中身の言葉ぶんで、収まらなければ止まる

### `timeline` の書き方

```toml
[[pages]]
kind = "declare"
type = "timeline"
title = "…"
periods = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]   # 列 = 期間 (左から右)
phases = [                                             # 任意。期間の上に掛ける帯
  { from = 0, to = 3, label = "flexible" },
  { from = 3, to = 6, label = "fixed deadlines" },
]
milestones = [ { at = 5.6, text = "Expo" } ]           # 任意。全レーンを貫く日付
links = [ { from = "build", to = "docs" } ]            # 任意。棒どうしの矢印 (= 棒の `id` で結ぶ)

[[pages.lanes]]                                        # レーン = 上から下
name = "Core"
tone = "tint"                                          # 任意。このレーンの棒の色の役
bars = [
  { from = 0, to = 1, text = "1.0 complete" },
  { from = 2.5, to = 3, text = "event (if any)", tentative = true },   # 点線の枠
  { from = 1, to = 2.5, text = "build", strong = true, tone = "accent", icon = "core.png", id = "build" },   # 見た目の 4 つと、`links` が指す名前
  { from = 3, to = 5, text = "shared work", spans = 2 },   # 任意。このレーンと下のレーンにまたがる
  { from = 0, to = 2, text = "name\n(note 1)\n(note 2)" },  # 名前の中の改行は、行になる
]
marks = [ { at = 1, text = "1.0 release" } ]           # レーンの中の菱形
```

- **位置は期間の番号** ― 0 が最初の期間の頭、`periods` の数が最後の期間の終わり、半期間なら 0.5
- **期間は列ごとに見出しの枠を持つ** (= 表の見出しと同じ地に太字)。列は 1 つおきにごく薄い地で
  塗られ、境に線が立つ (= どの棒がどの期間に掛かるかを、見出しから下へ辿れる)。`phases` の帯は
  その上に、端を期間の枠と揃えて置かれる
- **文字は 12pt か 14pt** ― 頁に収まるなら 14pt、詰まった頁は 12pt (= 1 頁の中では全部同じ大きさ)。
  レーンの名前は 14pt の太字。余った高さは棒の高さに配られ、頁の下に空きを残さない
- ⚠ **`phases` と `milestones` と `links` は最初の `[[pages.lanes]]` より上に書く** (= TOML では、
  `[[pages.lanes]]` の下に書いたキーはそのレーンのキーになる。下に書くと拒まれる)
- **レーンの `tone`** は `flow` のノードと同じ語彙 (= `box` / `band` / `tint` / `accent` / `good` / `bad`)。
  書かなければ `box` と `band` の交互。薄い地は 3 つ (= `box` / `band` / `tint`) で、**3 者までを
  色で分けられる**。濃い地 (= `accent` / `good` / `bad`) の上の名前は紙の色になる
- **薄い地の棒は、その地を濃くした色の細い枠を持つ** (= 列の薄い地の上でも棒の端が読める)。
  濃い地の棒に枠は無く、`tentative` の棒は点線の枠のまま
- 同じレーンで時期が重なる棒は、自動で段が分かれる
- **棒は `spans` で下のレーンへまたがれる** (= `spans = 2` はこのレーンと 1 つ下。2 つのレーンに
  分けた仕事の、共通の時期を 1 本で描く)。色は書いたレーンのもの、名前はいつも棒の中。
  ⚠ **またがる棒は、覆うレーンの高さを全部取る** ― その時期 (= 両端を含む) に、覆われるレーンへ
  置いた棒と印は拒まれる。端が接するだけの棒は置ける。覆われるだけのレーンは `bars` を書かなくてよい
- 棒の名前は棒の中。2 行でも収まらない名前は棒の隣へ出る。印の名前も隣 (= 右が先、端では左)
- **名前に改行 `\n` を書ける** (= 補足を 2 行目から)。全部の行が同じ揃えで、行の数 (= 折り返しも数える) だけ
  棒が高くなる。余った高さの配られ方は、改行の無い棒と同じ。隣へ出る名前も、行の数ぶんの高さを取る
- **棒どうしは矢印でつなげる** ― 棒に `id` (= 頁の中で 1 つの名前) を付け、頁の `links` に `{ from = "id", to = "id" }`
  を書く。書き方も読み方も `compose` のマスどうしの線と同じで (= 上の「マスどうしの線」)、`tone` と
  `text` も書ける。矢印は 2 つの棒の向き合う端から端へ引かれ、間に別の棒・印・棒の隣の名前が在れば止まる
  (= 矢印がそれらを横切らない)。向き合わない 2 つと知らない `id` も止まる。棒の隙間は狭い
  (= `bar_gap`) ので、同じ段で続く棒どうしの矢印は短い
- 文字は全部 pptx の文字 (= PowerPoint で直せる)。棒は名前ごと 1 つの図形
- 収まらない頁は縮めずに止まる (= レーンを減らすか、2 頁に分ける)

### `chart` の書き方 (= 数字から描くグラフ)

```toml
[[pages]]
kind = "declare"
type = "chart"
title = "…"
footer = "出所: …"                                    # データの頁には出所を書く (= 検査 unsourced)

[pages.chart]
kind = "column"                                        # bar / column / line / stacked / waterfall / scatter / strip
categories = ["Q1", "Q2", "Q3", "Q4"]                  # 項目 (= 何の数字か)
x = "四半期"                                            # 横の軸の名前 (= 横棒 bar では値の軸。単位も書く)
y = "売上 (百万円)"                                     # 縦の軸の名前 (= 値の軸の名前が無ければ検査 unnamed_axis)
series = [                                             # 系列 (= 1 つ以上)
  { name = "売上", values = [12, 15, 21, 18] },         # 値は項目と同じ数
]
highlight = "Q3"                                       # 任意。目立たせる 1 つ (= 系列か項目の名前)
highlight_tone = "accent"                              # 任意。目立たせる 1 つの色 (= 下の「目を集めるのは 1 つ」)
unit = "%"                                             # 任意。数字の後ろに付く字
labels = false                                         # 任意。値の数字を付けない (= 既定は付ける)
callouts = [{ at = "Q3", text = "…" }]                 # 任意。1 点を指す注記 (= 下の「注記」)
scale = { from = 1, to = 5, step = 1 }                 # 任意。値の軸の下限・上限・目盛りの間 (= 下の「値の軸の範囲」)
bare = true                                            # 任意。棒と項目名だけを描く (= 下の「棒だけの小さなグラフ」)
notes = ["…", "", "…"]                                 # 任意。横棒 (bar) の、項目ごとの 1 行の説明 (= 下の「名前の下の説明」)
```

- **伝えたいことで種類を選ぶ** ― 比べるなら `bar` (= 横棒。項目の名前が長い時) か `column` (= 縦棒)、
  移り変わりなら `line`、内訳なら `stacked` (= 積み上げた縦棒)、増減の積み重ねなら `waterfall` (= 滝グラフ)、
  2 つの量の関係なら `scatter` (= 点。書き方は下の「点のグラフ」)、区分ごとの分布を 1 件 1 点で見せるなら
  `strip` (= 対数の軸に並べた点の列。書き方は下の「点の列」)。棒と折れ線を重ねるグラフは無い
- **数字は deck の中に入る** ― PowerPoint でグラフを選んで「データの編集」を開くと、表で数字を直せる
  (= 絵ではないので、形はその場で変わる)
- **数は manifest に書くか、CSV から読む** ― `data = "sales.csv"` (= 素材の folder。1 列目が項目、
  2 列目からが系列、1 行目が系列の名前)。`data` を書いたら `categories` と `series` は書かない
- **目を集めるのは 1 つ** ― `highlight` に書いた 1 つだけが差し色で、ほかは灰。系列が 1 つなら項目の名前、
  2 つ以上なら系列の名前を書く (= 系列と項目に同じ名前が在ると拒まれる)。差し色が頁の上で別の意味の色に
  なっている時は、`highlight_tone` でその 1 つを別の色にする (= 目次の `highlight_tone` と同じく、道具の色の役か
  `[theme.grounds]` で名前を付けた地。墨にしたい時は墨の色の地に名前を付ける)。点のグラフと点の列も同じ
- `highlight` を書かない時の色 ― 系列が 1 つなら差し色。2 つ以上なら、最初の系列が差し色で、続きは
  濃い灰、薄い灰。**4 つめからの系列は `tone` を自分で書く** (= 見分けられる灰が 2 つまでなので)
- 系列の `tone` は箱と同じ語彙 (= `box` / `band` / `tint` / `accent` / `good` / `bad` か、`[theme.grounds]` の名前)。
  `highlight` と一緒には書けない。薄い地の系列は、箱と同じく地を濃くした色の枠を持つ
- **値の数字は 1 度だけ見せる** ― 棒の外の端 (= 折れ線は点の上、積み上げは段の中) に付き、その時は値の軸を
  出さない。`labels = false` なら数字を付けず、値の軸が出る。目盛りの線はどちらでも引かない (= `scale` を
  書いたグラフを除く)
- **軸の名前は `x` (= 横の軸) と `y` (= 縦の軸) に、単位も含めて書く** ― 点のグラフと同じ鍵と同じ意味で、横棒
  (`bar`) は値の軸が横なので `x` が値の軸。名前は軸の外に本文の大きさで出る (= 縦の軸は回して左に)。値の数字を
  棒に付けて値の軸を隠したグラフでも、値の軸の名前だけは出る (= 何の数かは数字だけでは読めない)。**値の軸の
  名前が無いグラフは検査 `unnamed_axis` が知らせる** (= 縦のグラフは `y`、横棒は `x`)。項目の軸の名前は、項目が
  何かを項目の名前が言っていれば省いてよい
- **負の値を持つグラフは、項目の名前を軸の外側の端に置く** ― 横棒は描く範囲の左端、縦のグラフは下端。0 の所に
  置くと、負の棒とその先の数字が名前に重なる。0 の線は引いたまま
- **値の軸を隠したグラフは 0 から立つ** ― 棒の高さが値の比になる (= 近い値ばかりでも、67 の棒が 75 の棒の
  半分に見えることは無い)。0 以外から立たせたい時は `scale` を書く (= その時は軸が出る)
- **値の軸の範囲 (`scale`)** ― 5 段階・7 段階の評価や割合 (= 0〜100%) のように、読み手が「どの範囲のどこか」を
  目で測るグラフに書く。書いたグラフだけ、値の軸が `from` から `to` まで出て、`step` ごとに薄い目盛りの線が
  引かれる。数字は棒に付いたまま (= `labels` はそのまま効く)。下限が 0 でない時、棒は途中から立つ ― 軸が
  必ず出るのはそのため。範囲の外の値 (= 枠で切れる棒) と、割り切れない `step` と、20 を超える目盛りは拒まれる。
  積み上げは `from = 0` から (= 下の段が切れる)。滝グラフと注記付きのグラフには書けない (= どちらも軸を
  道具が別に決める)
- 数字は、書いた中でいちばん細かい桁に揃えて出る (= `12.5` と `21.25` が在れば全部 2 桁)。3 桁ごとに区切る
- **凡例は系列が 2 つ以上の時だけ**、グラフの下に出る。字の大きさは本文と同じ
- `bar` は最初の項目が上 (= 表と同じ読み順)。値の軸を出す時は、グラフの下に出る

#### 棒だけの小さなグラフ (`bare = true`)

```toml
chart = { kind = "column", bare = true, categories = ["2022", "2023", "2024", "2025"],
          series = [{ name = "論文", values = [4, 9, 15, 11] }], highlight = "2024" }
```

- **数字も値の軸も出さず、棒と下の項目の名前だけを描く** ― 小さな図を区画ごとに並べる頁 (= 研究の地図) で、
  棒の高さの比だけを見せる。値の軸を隠したグラフと同じく 0 から立つ (= 高さが値の比)
- `bar` と `column` だけに書ける。数字や軸を言う `labels` / `unit` / `scale` / `callouts` とは一緒に書けない
  (= 言うことが食い違うので拒まれる)。`highlight` と凡例は今までどおり
- 数字は deck の中に残る (= PowerPoint の「データの編集」で見える)。項目の名前の字は本文の大きさ

#### 名前の下の説明 (`notes`)

```toml
chart = { kind = "bar", categories = ["街角", "商品", "地図"], series = [{ name = "枚数", values = [120000, 84000, 6000] }],
          notes = ["公開のアーカイブ", "白い背景", ""] }
```

- **横棒 (`kind = "bar"`) の、項目の名前の下に 1 行の説明を添える** ― 項目と同じ数だけ書く (= 言うことが無い項目は
  `""`)。説明は 1 行で、改行は入れない。名前と同じ右端に揃い、小さく灰色で出る
- 名前は PowerPoint の軸の字のまま (= 数字と一緒に「データの編集」で直せる)。説明は道具が置く場所を計算して
  書くので、**描く範囲と値の軸を道具が決めて書き出す** (= 注記 `callouts` と同じ。数字を大きく直す時は
  manifest を直して焼き直す)。説明はグラフと 1 つのグループにまとめてある
- 項目の帯が、名前と説明の 2 行より低ければ頁が止まる (= 棒を減らすか、グラフに高さを渡すか、説明を外す)
- `scale` とは一緒に書けない (= どちらも値の軸を道具が別に決める)。`callouts` とは一緒に書ける
  (= 説明は左、注記は右)

#### 点のグラフ (`kind = "scatter"`)

```toml
[pages.chart]
kind = "scatter"
x = "かけた時間 (h)"                                    # 必須。軸の名前 (= 単位も書く)
y = "満足度"                                            # 必須
series = [
  { name = "A 案", points = [[1, 2.5, "試作"], [2, 3.5], [3.5, 5]] },   # 点 = [x, y] か [x, y, "名前"]
  { name = "B 案", points = [[1.5, 1], [4, 2]] },
]
highlight = "A 案"                                      # 任意。目を集める系列
grid = true                                             # 任意。薄い格子 (= 既定は引かない)
```

- **項目を持たない** ― 系列は点 (= x と y の 1 組) の集まり。`categories` も `values` も書かない
- **軸の名前は必ず書く** (= 軸が何かを言わない散布図は読めない)。軸は 2 本とも出て、目盛りの線は引かない
- 色は、ほかのグラフと同じ決まり (= 最初の系列が差し色で続きは灰、`highlight` か系列の `tone` で変える)。
  凡例は系列が 2 つ以上の時だけ
- CSV から読む時は `data = "points.csv"` ― 1 列目が x、2 列目からが系列の y、1 行目が系列の名前。
  空のマスは「その系列は、この x に点を持たない」
- 点に数字は付かず、注記 (`callouts`) も `unit` / `labels` / `totals` も読まない (= 書くと拒まれる)
- **点に名前を付けると、点の横にその名前と数字が出る** ― 点を `[x, y, "名前"]` と書く (= 名前の無い点は
  `[x, y]` のまま。1 行の短い言葉)。名前の下に、`(x, y)` が書いた中でいちばん細かい桁に揃って出る。
  言葉は点の右、グラフの縁に届く点は左。**言葉どうしが重なるなら頁が止まる** (= ずらさない、縮めない。
  名前を付ける点を減らす)
- ⚠ **名前を付けた散布図は、描く範囲と軸を道具が決めて書き出す** (= 言葉の場所を計算するため。軸は点の範囲より
  少し広く、目盛りは 1・2・5 の倍数)。言葉は書いた時の字で、PowerPoint で数字を直しても変わらない ―
  数字が変わる時は manifest を直して焼き直す。名前の無い散布図は、今までどおり PowerPoint が決める。
  言葉はグラフの一部 (= 点のラベル) なので、グラフを動かせば付いて来る
- **`grid = true` で、薄い格子を両方の軸に引く** (= 点の位置を目盛りに当てて読む図に。既定は引かない。
  散布図だけに書ける)

#### 点の列 (`kind = "strip"`)

```toml
[pages.chart]
kind = "strip"
axis = "log"                                            # 必須。横の軸は対数 (= 10 の累乗ごとに目盛り)
ticks = [1, 10, 100, 1000]                              # 必須。10 の累乗を小さい方から、抜けなく。軸の両端になる
categories = ["街角\n写真\n商用可", "商品"]               # 行。名前は \n で 2〜3 行にできる
notes = ["1,200 件", "340 件"]                           # 任意。行ごとの 1 行 (= 点の列の右に出る。"" は無し)
series = [                                              # 系列 (= 点の色)
  { name = "小", values = [[3, 12, 40], [8, 15]] },       # 値は行ごとの数の並び (= 点の無い行は [])
  { name = "大", values = [[900], []], tone = "bad" },
]
median = true                                           # 任意。行ごとの中央値を白抜きの輪で
highlight = "小"                                        # 任意。目を集める系列 (= 色はほかのグラフと同じ決まり)
legend = false                                          # 任意。凡例を出さない (= 凡例を別の欄で言う時)
```

- **行 = 項目、横 = 対数の軸、1 件 = 点 1 つ** ― 区分ごとの量の分布を、まとめずに 1 件ずつ見せる図。
  点は PowerPoint の散布図で描く (= 数は deck の中に在り、「データの編集」で直せる)
- **軸は `axis = "log"` と `ticks`** で言う。対数の軸が目盛りを打てるのは 10 の累乗だけなので、`ticks` は
  `[1, 10, 100, 1000]` のように 10 の累乗を抜けなく並べる (= 1・3・10 のような目盛りは拒まれる。0.1 や 0.01 も書ける)。
  先頭と末尾が軸の両端で、**範囲の外の点は拒まれる** (= 枠で切れる点を黙って出さない)。0 以下の数は書けない
- **点どうしが覆い合わないよう、行の中で縦にずらす** (= 近い数は上下に並ぶ。同じ数も重ならない)。ずらし方は
  数と大きさだけで決まるので、焼き直しても同じ。PowerPoint の表の縦の列は、行の番号に小さなずれを足した数
- **`median = true` で、行ごとの中央値を白抜きの輪で** (= 行の点を全部合わせた真ん中の数。偶数個なら中の 2 つの
  平均)。点より一回り大きく、点の上に重なる。表には `Median` という名前の列が増える (= 系列の名前に
  `Median` は使えない)
- **行の名前は点の列の左、`notes` は右に置く** (= 行の真ん中。名前は本文の大きさ、`notes` は小さく灰色)。
  描く範囲と軸を道具が決めて書き出し (= 言葉の場所を計算するため)、言葉はグラフと 1 つのグループにまとまる。
  行が名前の行数より低ければ、頁が止まる (= 行を減らすか、グラフに高さを渡すか、名前を短く)
- 凡例は、系列が 2 つ以上 (= `median` の輪も 1 つに数える) の時に下に出る。`legend = false` で消せる
- 色は、ほかのグラフと同じ決まり (= 最初の系列が差し色で続きは灰、`highlight` か系列の `tone` で変える。
  `highlight` と `tone` は一緒に書けない。4 つめからの系列は `tone` を書く)
- 数は manifest に書く (= CSV は読まない)。`unit` / `labels` / `callouts` / `grid` は書けない
  (= 点に数字は付かず、格子は軸と行の境に自動で引かれる)

#### 注記 (`callouts`)

```toml
[pages.chart]
kind = "column"
categories = ["Q1", "Q2", "Q3", "Q4"]
series = [{ name = "北", values = [12, 15, 21, 18] }, { name = "南", values = [8, 9, 14, 16] }]
callouts = [
  { at = "Q3", series = "北", text = "新製品が出た" },   # どの項目の、どの系列を指して、何と言うか
]
```

- **座標は書かない** ― 書くのは項目の名前 (`at`) と系列の名前 (`series`) と一言 (`text`)。点の位置は道具が計算し、
  言葉をグラフの外に、細い線を点の手前 (= 棒に付いた数字の外) まで置く
- 言葉の場所 ― 縦のグラフ (= `column` / `line` / `stacked` / `waterfall`) は**グラフの上**、指す点の真上。
  `bar` (= 横棒) は**グラフの右**、指す棒と同じ高さ。グラフはそのぶん小さくなる
- 系列が 1 つなら `series` は省ける。**`stacked` と `waterfall` は柱 1 本を指す** (= `series` は書けない。
  どの段の話かは言葉で言う)
- 一言は 1 行。1 つの点に注記は 1 つ。**言葉どうしが重なるなら頁が止まる** (= ずらさない、縮めない。
  言葉を短くするか、注記を減らす)
- 折れ線で下の系列の点を指すと、線が上の系列を横切る
- **注記を持つグラフは、描く範囲と値の軸を道具が決めて書き出す** (= 点の位置を計算するため)。
  ⚠ PowerPoint で数字を大きく直すと、棒が値の軸の端を越えたり、注記が点から外れたりする ―
  数字が変わる時は manifest を直して焼き直す。注記の無いグラフは、今までどおり PowerPoint が決める
- グラフと注記は 1 つのグループにまとめてある (= PowerPoint でグラフを動かしても、注記が付いて来る)

#### 滝グラフ (`kind = "waterfall"`)

```toml
[pages.chart]
kind = "waterfall"
categories = ["前年", "新規", "値上げ", "解約", "今年"]
series = [{ name = "利益", values = [100, 42, 8, -30, 120] }]   # 系列は 1 つ。増えた分は正、減った分は負
totals = ["前年", "今年"]                                       # 合計の項目 (= 地面から立つ棒)
unit = "M"
```

- 書くのは**増減の値だけ**。棒を浮かせる位置は道具が計算する
- `totals` に書いた項目は合計の棒 ― 最初の項目なら出発点の値、途中や最後なら、**そこまでの増減を足した値と
  同じでなければ拒まれる** (= 食い違う数字を載せない)
- 色は意味で決まる (= 増えた分は `good`、減った分は `bad`、合計は差し色)。`highlight` と `tone` は書けない
- ⚠ **1 つの段が 0 をまたぐ滝グラフは描けない** ― 0 で 2 つの段に分けて書く
- PowerPoint の表には、台・増えた分・減った分・合計の 4 列が並ぶ (= 台の列は、棒を浮かせるための透明な系列)

## どの型にも添えられるもの

`cards` / `card_columns` / `table` / `note` / `points`

`card_columns` = カードを何枚ずつ並べるか (= 省略すると全部 1 段)。`figure_grid` の `columns` とは別の数。
カードは flow のノードと同じ 2 通りで書ける (= `["見出し", "本文"]` か `{ heading, body, tone, icon }`)。

### 表のセルの状態の印

表 (= `table`。`board` の表も、`compose` のマスの表も同じ) のセルには、言葉の代わりに印を 1 つ書ける:

```toml
table = [
  ["項目", "進み", "状態"],
  ["設計", { harvey = 4 }, { mark = "ok" }],
  ["試作", { harvey = 2 }, { mark = "partial" }],
  ["評価", { harvey = 0 }, { mark = "ng" }],
]
```

- **`{ harvey = 0〜4 }`** ― 4 分の幾つが済んだか (= ハーベイボール。○ ◔ ◑ ◕ ●)
- **`{ mark = "ok" | "partial" | "ng" }`** ― 良い・半ば・悪い (= ✓ △ ×)
- ⚠ **印の字を直に書かない** (= `"○"` と書くと言葉として扱われ、案件の書体に字形が無ければ別の字になる)。
  印として書いたセルは、字形を持つ書体で置かれる ― 字のままなので PowerPoint で直せる
- 印の大きさと寄せは、ほかのセルと同じ。色は付かない

**値の大小を、セルの地の濃さで見せる** (= 表を読む前に、どこが濃いかが目に入る):

```toml
table = [
  ["地域", "先月", "今月"],
  ["北", { text = "12%", shade = 1 }, { text = "48%", shade = 2 }],
  ["南", { text = "71%", shade = 3 }, { text = "96%", shade = 4 }],
]
```

- **`{ text = "…", shade = 0〜4 }`** ― 地は差し色を 4 分の幾つかに薄めた色 (= 4 が差し色そのもの、0 は
  ふつうのセル)。字は、その地の上で読める方の色 (= 濃い地では紙の色) になる
- **段を決めるのは書く人** ― 何を境に濃くするかは、その表が何を言いたいかで決まる。同じ表の中では
  同じ境で段を振る
- 見出しの行には書けない (= 見出しは差し色の地)。印と濃さを 1 つのセルに一緒には書けない

### 表を区切る行 (= `{ band = "…" }`)

行の途中に、**表の幅いっぱいに立つ見出しの行**を置ける (= 表を、いくつかのまとまりに分ける)。セルの並びの代わりに
`band` を持つ表を 1 行として書く:

```toml
table = [
  ["畑", "植えた日", "収量"],
  { band = "春", tone = "accent" },
  ["北", "3 月 12 日", { text = "48 kg", shade = 2 }],
  ["南", "3 月 30 日", { text = "71 kg", shade = 4 }],
  { band = "秋" },
  ["西", "9 月 2 日", "9 kg"],
]
```

- **`band`** ― その行の言葉 (= 太字、表の幅いっぱい)。**`tone`** ― 色の役 (= 箱と同じ語彙。
  `accent` / `good` / `bad` / `box` / `band` / `tint` と、`[theme.grounds]` の名前)。書かなければ、見出しの行と
  同じ灰の地に本文の色
- **`table_look` を問わず書ける。** 色の出し方だけが見た目で変わる: `"accent"` の表は箱と同じに行の地を
  `tone` の色で塗り (= 差し色なら濃い地に紙の色の字)、`"plain"` の表は枠を色で言うカードと同じに、色を字が
  持つ (= 地はほぼ紙の色)。薄い地の役 (= `box` / `band` / `tint`、薄い `[theme.grounds]`) は、どちらも地を
  その色にして字は本文の色
- **見出しの行は、列のセルで書く** (= 区切りは見出しの下の行を分ける)。区切りで終わる表も拒まれる
  (= その下に行が無い)。`band` と `tone` のほかのキーも拒まれる
- 区切りの行は表の幅いっぱいに置かれ、**列の幅を決めない** (= 長い区切りで 1 列目が広がらない)。
  本文の縞は、区切りの行を数えずに続く

### 表を CSV から読む (= `table = { data = "…csv" }`)

表の行を manifest に書き写さず、素材の folder の CSV をそのまま表にできる (= 結果の file から機械で出した表が、
材料を直すたびに古くならない)。`board` の表も、頁に添える表も、`compose` のマスの表も、同じ書き方で読む。

```toml
# 素材の results.csv ― 1 行目が見出しの行
#   手法,値,備考
#   A,0.50,速い
#   B,1.25,遅い
table = { data = "results.csv" }
```

- **`data`** (= 必須) ― 素材の folder の CSV の名前 (UTF-8。先頭の BOM と空の行は読み飛ばす)。**1 行目が表の
  見出しの行**、2 行目からが本体。セルは CSV の字のまま置く (= 数を整えない。前後の空白だけ落とす)
- **`columns`** (= 書かなくてよい) ― 残す列を、CSV の見出しの字で並べる。**書いた順が表の列の順**。書かなければ
  CSV の全部の列を、その順に置く

  ```toml
  table = { data = "results.csv", columns = ["手法", "備考", "値"] }
  ```

- **`cells`** (= 書かなくてよい) ― 特定のセルの字を変える。手で注を足したいセル (= 値の後ろに、なぜその値かの
  短い注) のための物で、CSV 自体は書き換えない。1 件が 1 つのセルを指す:
  - **`row`** ― そのセルの行の 1 列目の字 (= CSV の 1 列目。`columns` で 1 列目を外していても、CSV の 1 列目で探す)
  - **`column`** ― CSV の見出しの字
  - **`after`** ― 値の後ろにそのまま足す字 (= 区切りの空白や括弧は書く人が書く)。**`text`** ― セル全体を置き換える字。
    `after` と `text` はどちらか 1 つ

  ```toml
  table = { data = "results.csv", cells = [
    { row = "B", column = "値", after = "（再測定）" },   # 1.25（再測定）
    { row = "C", column = "備考", text = "―" },           # 普通 → ―
  ] }
  ```

**止まる場合** (= 黙って捨てない。CSV の行の名前が変わった日に、注が消えたのに気づけなくなるため):

- `data` が `.csv` でない・素材の folder に無い。UTF-8 の文字でない。見出しの行しか無い (= 本体の行が 1 つも無い)
- 行のセルの数が見出しの行と揃っていない (= 何行目かを言って止まる)
- `columns` が、見出しに無い名前・同じ名前の 2 回・空の並びを書いた。見出しが CSV に 2 つある名前を指した
- `cells` の `row` が、CSV の 1 列目に無い・2 つ以上ある (= 何行目かを言う)。見出しの行を指した。`column` が見出しに
  無い、または `columns` で外した列を指した。同じセルを 2 件で指した。`after` と `text` を両方、またはどちらも書かなかった
- 知らないキー ― **行の並べ替え・行の選び方・区切りの行 (`band`)・印 (`harvey` `mark`)・地の濃さ (`shade`) は
  書けない**。並びは CSV が決める。印や濃さのセルが要る表は、行を manifest に書く
- CSV に空のセルがある (= 行で書いた表と同じ。値が無いなら、`cells` の `text = "―"` で置く)

出所 (`footer`) は、CSV から読んだ表でも行で書いた表と同じに要る (= 検査 `unsourced`)。

⚠ **その型が読まないキーは拒まれる** (= 書いたつもりで頁に無い、を作らない)。

⚠ **縮むのは絵だけ**。言葉を持つ物 (= カード・表・文章・要点・目次の一覧と章の箱) は、自分の言葉ぶんの
高さが取れなければ頁が止まる。絵も、高さが足りずに 1.2cm (= アイコンの一辺) より低くなるなら止まる
(= 横に長い絵が幅いっぱいで低いのは構わない)。

## 枠まわり (= どの頁も同じ順)

`kicker` / `title` / `condition` / `conclusion` / `footer` / `replace` / `legend` / `sticker`

`legend = false` は、その頁の凡例を消す。`legend = true` は、使った名前が 1 つだけでも凡例を出す (= 書かなければ、名前が 2 つ以上の時だけ出る。下の「意味の名前を付けた地」)。

**`sticker = "暫定"` は、頁の性格を言う札** (= 暫定・イメージ・抜粋)。題の帯の右端に、灰の細枠に灰の字で
1 つ立つ。題はそのぶん狭い幅で折れる (= 札の下へは回り込まない)。1 頁に 1 つ、1〜2 語で書く ―
題が置けなくなるほど長い札は拒まれる。

**題は 2 行まで**。2 行に折れた題は、題の帯が 1 行ぶん伸び、本体はそのぶん下から始まる (= 題が本体に
重ならない。いっぱいまで詰めた頁は、題が折れると止まり得る)。3 行に達した題は検査 `long_title` が知らせる。

**型の頁が乗るレイアウト** ― 既定は、部品の名前が `slideLayout1.xml` のレイアウト (= 見本の頁の並びの
1 枚目ではない。並べ替えても変わらない)。書き出した道具によってはその部品が表紙の型で、型の頁が表紙の飾りの
上に乗る (= Google スライドの書き出し)。その時は、本文の頁を 1 枚、頁の番号で名指す:

```toml
[theme]
layout_of_page = 3     # 見本の 3 枚目の頁と同じレイアウトに乗る (= 同じ名前のレイアウトが 2 つ在っても 1 つに決まる)
```

**題の色と書体はテンプレートのもの** ― そのレイアウトに題の枠が在れば、題はその枠として書かれ、色・書体・
太さをテンプレートから継ぐ (= 複製した頁の題と揃う)。**題の帯の高さも、その枠に合わせる** (= レイアウトが
場所を書いていなければマスターの題の枠。複製した頁の題と同じ高さに出る)。枠の中を頁を横切る罫線が通る
テンプレートでは、帯はその線の手前で止まる。左右の幅と字の大きさは道具が決める ― 大きさをテンプレートに
合わせるなら `[theme.type]` の `title` に書く。題の枠が無いレイアウトでは、題は本文の色の太字で書かれる。

**レイアウトの線が題の字を横切る頁は止まる** ― 取り消し線に見えるので、build が線の名前と高さを言って止まる。
直すのは乗せるレイアウトの方 (= `layout_of_page` で、題の下に線を引く本文の頁を名指す)。題の後ろに敷く地
(= 帯の色の矩形や絵) は数えない。

**題と札は、レイアウトが印字する物の手前で止まる** (= 隅のロゴ)。題はその幅で折れ、札はロゴの手前に立つ。
書く物は無い ― テンプレートを読んで決まる。

**本体は、テンプレートが題の下に引いた罫線の下から始まる** ― 題の帯の高さは使い方で変わるが (= 字の小さい
使い方の頁は帯が低い)、テンプレートの罫線は動かない。罫線が本体の始まる所より下に在る頁は、本体を罫線の下
から始め、題の下の線を自分では引かない (= 線はテンプレートのもの 1 本)。罫線が題の字の下から帯のすぐ下までに
在る頁も、題の下の線は自分では引かない (= 2 本にならない)。

**本体は、テンプレートが頁の足元に引いた線の手前で終わる** ― 頁の下半分に、頁を横切って印字される物 (= 頁番号や
注記の上の線、足元の帯) が在れば、いちばん上の物の上端から頁の縁の余白を取った所が本体の下端になる (= 線より
下はテンプレートのもの)。足元に何も無いテンプレートでは、頁の下端から同じ余白を取る。書く物は無い。

**頁番号はテンプレートのもの** ― テンプレートの頁が頁番号を持つ (= PowerPoint で「スライド番号」を入れて
ある) なら、型の頁も、乗るレイアウトの頁番号の枠を持つ。番号は複製した頁と同じ所に、同じ見た目で出る
(= 位置も字もレイアウトのもの。番号は開いた側が入れる)。書く物は無い。番号が出ない時に見るのは 2 つ ―
テンプレートの頁が頁番号を持っているか、型の頁が乗るレイアウトに頁番号の枠が在るか。

**表紙は数えない** ― 資料の 1 枚目が頁番号を持たず (= 表紙)、後ろの頁が持つとき、番号は 0 から数え始める
(= 表紙の次の頁が 1。PowerPoint の「スライド開始番号」に 0 を書く)。1 枚目が番号を持つ資料 (= 表紙の無い、
1 枚目から本文の資料) は 1 からのまま。テンプレートが開始番号を自分で書いていれば、それがそのまま通る。
⚠ **焼いた絵では、表紙の次の頁が 2 のまま出る** ― 絵を焼く LibreOffice は開始番号を読まない。PowerPoint で
開くと 1 から出る。

## 見た目 (= `workspace.toml`)

**テンプレートは写さずに指せる。**`template = "<folder>"` (= この `workspace.toml` からの相対か絶対) を書くと、
その folder の `workspace.toml` を読み、この案件の設定をその上に重ねる (= 同じ表は鍵ごとに案件の値が勝つ。
`root`・`paths` は案件の物のまま)。`specimen.pptx` も、案件の folder に無ければテンプレートの物を使う。
テンプレートが上げ直されても、案件の側は替え直さなくてよい。指せるのは 1 段だけ。
**使い方 (= `[theme.uses.<名前>]`) は名前で 1 まとまり** ― テンプレートと同じ名前の使い方を案件に書くと拒まれる
(= 鍵ごとに重ねると、書かなかった字の大きさと余白がテンプレートのまま混ざる)。案件の使い方には別の名前を付ける。

```toml
template = "~/templates/company"
```

```toml
[theme]
font = "Arial"

[theme.palette]
ink = "424242"      # 本文
accent = "2E9E5B"   # 読みを示す色 (= 表の見出しもここ)
band = "EAF0F8"     # 条件の帯
tint = "E8F3EA"     # 3 つめの薄い地 (= box / band と並べて 3 者を分ける。ここでだけ変えられる)
wash = "F3F3F3"     # 線表の列を 1 つおきに塗る地・`table_look = "plain"` の表の見出しの地 (= ここでだけ変えられる)
rule = "D9D9D9"     # 細い線の色・`table_look = "plain"` の表の罫線
```

### カードの字の置き方 (= `heading` を省く・`align`・`tag`・箇条書き)

カードと、flow・道のりのノード、`compose` のカードは、上の 4 つのほかに次の 4 つを読む (= 棒と矢羽根は読まない):

| キー | 意味 | 見た目 |
|---|---|---|
| `heading` | 省ける (= 本文だけのカード。両方省けば、相手が書き込む空の枠) | 本文だけが箱の字になる。空の枠は字の分の高さが無いので、頁の高さを使い切る資料 (= `box_height = "page"`) か、`compose` の段の高さで使う |
| `align = "center"` | 字を中央寄せにする (= 書かなければ `"left"`) | 見出しも本文も中央寄せ |
| `tag = true` | 札 (= 段の名前や番号を 1 行で言う箱) | 薄い灰の地に、`tone` の色の枠と太字の見出しを 1 行・中央寄せで。見出しだけを持つ (= `body` と `icon` は書けない) |
| `body = ["…", "…"]` | 配列で書くと、1 件が「•」の 1 行 | 点は段落の書式で付く (= 折り返した行は字下げされ、PowerPoint で行を足しても点が付く)。文字列は今までどおり段落 |

```toml
cards = [
  { body = "見出しの無いカード。本文だけを置く", align = "center" },
  { heading = "段 1", tag = true, tone = "bad" },
  { heading = "分かったこと", body = ["1 件が 1 つの点", "長い件は折り返して、点の右にそろう"], tone = "accent" },
  { tone = "tint" },                                    # 見出しも本文も無い空の枠
]
```

- **札は 1 行に収まる字数で書く** (= 折れるなら止まる。段の名前か番号を 1〜2 語で)。札の字の大きさは `[theme.type]` の `tag` で決まる (= 書かなければ見出しの大きさ。下の「文字の大きさ」)
- **配列の 1 件に改行は書けない** (= 点が付くのは 1 件に 1 つ。2 行にしたいなら 2 件に割る)。空の配列と、
  空の 1 件も拒まれる
- **`card_look = "outlined"` の資料では、カードの字は箱の縦の中央に置かれる** (= 見出しと本文を 1 つの塊として、
  箱の真ん中へ。字が箱いっぱいなら上から)。`"filled"` の資料は今までどおり上から。頁ごと・カードごとには変えられない。
  **字が 1 つだけのカード** (= 札、本文だけのカード、見出しだけのカード) は、字の枠が箱の内側いっぱいで、字は
  その枠の縦の中央に置かれる (= 札は `"filled"` の資料でも)。隣の箱と字の大きさが違っても、枠の上端は揃う

⚠ **書体と色は、ふつうは書かない** ― 見た目は `specimen.pptx` から読まれる。ここに書くのは、
テンプレートの配色がツールの色の使い方と合わないときだけ。案件が決められるのは**書体・色・文字の大きさ**
(= 下の「資料の使い方」)。余白と間隔は、ふつうはツールが持つ ― 動かせるのは、案件が名前を付けた使い方の
中だけ (= 下の「案件の使い方に名前を付けて足す」)。

### 資料の使い方と文字の大きさ (= `[theme] use` と `[theme.type]`)

```toml
[theme]
use = "present"        # "read" (= 既定) / "present" / "sheet" ― どれが何の資料かは下の表

[theme.type]           # 任意。役ごとの上書き (= pt)
body = 20
```

**題の上の小さい字の置き場** (= `kicker`) も案件が決める:

```toml
[theme]
kicker = "beside"      # "above" (= 既定。題の上に小さく) か "beside" (= 題の左に同じ行で、差し色の太字)
```

`beside` は題の 1 行目に並び、題はそのぶん狭い幅で折れる (= 番号と 1〜2 語で書く。題が置けなくなるほど
長ければ拒まれる)。帯の高さは `above` の時と同じ。資料全体の見た目なので、頁ごとには変えられない。

字の大きさは `[theme.type]` の `kicker` で決める (= 下の表。書かなければ、`above` は出所の字、`beside` は題の字)。
題より小さくした `beside` も、題と同じ段落の頭の字として書くので、**字の下の線は題と揃い**、折れた題の行は
題の列に揃う。`above` は題の上の段の高さもこの大きさに付いて行く。**`[theme.type]` に書いた `kicker` は、
案件の使い方 (= `[theme.uses.<名前>]`) にも届く** (= 資料全体の見た目なので。使い方が自分の `kicker` を
書けばそちらが勝ち、その使い方の下限より小さければ拒まれる。道具の使い方 `read` / `present` / `sheet` には掛からない):

```toml
[theme]
kicker = "beside"

[theme.type]
kicker = 13            # 題 (= 例えば 20) より小さい差し色の太字
```

**箱の高さ・カードと線表の棒の見た目・上下の帯の見た目・表の見た目**も、資料全体の見た目として案件が決める。書かなければ
今までの見た目のまま (= どれも資料全体で 1 つ。決めると頁の形が変わる):

```toml
[theme]
box_height = "page"      # "text" (= 既定。箱は字の分の高さ)、"page" (= 頁の高さを箱で分け合って使い切る)、
                         # "middle" (= 箱は字の分の高さで、本体の塊を縦の中央に置く)
card_look = "outlined"   # "filled" (= 既定。地を塗る) か "outlined" (= 地はほぼ白、色は枠と見出しの字)
bar_look = "outlined"    # "filled" (= 既定。線表の棒の地を塗る) か "outlined" (= 地はほぼ白、色は枠。カードの `outlined` と同じ決まり)
band_look = "outlined"   # "plain" (= 既定。枠の無い灰の帯) か "outlined" (= 枠と色を持つ帯)
caption_look = "label"   # "plain" (= 既定。絵の下の名が出所と同じ灰の小さい字) か "label" (= 本文の色の太字)
table_look = "plain"     # "accent" (= 既定。見出しの行が差し色の地) か "plain" (= 見出しの行が灰の地、罫線が灰)
leading = 1.2            # 任意。行の高さ (= 字の大きさの倍率、1.0〜2.0)。書くと見積りも書き出しの行間もこの値になる
```

`box_height` と `table_look` と `leading` は、使い方ごと (= `[theme.uses.<名前>]`) にも選べる。`card_look` と `bar_look` と `band_look` と `caption_look` は資料で 1 つ。

- **`box_height = "page"`** は、箱が字の分の高さのまま頁の下半分が空く頁を、下端まで使う形にする。箱は
  自分の字の分の高さに、残りの高さの**等しい取り分**を足す (= 字の多い箱は字の少ない箱より高いまま)。
  効くのは `cards` の頁、`compose` のカードと入れ物を持つ段、`flow` / `roadmap` の段ごとのノード、`flow` の
  `direction = "down"` の段、`agenda` の章の箱。`compose` では、絵や型の段と `weight` を書いた段が残りを
  取り、取る段が無い時にだけカードの段が分け合う (= 絵は残りを使う)。カードを持たない段 (= 文章・表・
  要点だけ) と、カードが本体の上に添えられた頁 (= 本体が高さを取る) は、字の分のまま。入りきらない頁は、
  縮めずに止まる (= 今までと同じ)
- **`box_height = "middle"`** は、箱を `"text"` と同じ字の分の高さにしたまま、**本体に置かれた物の塊**
  (= カード・図・流れ・表・読み方・凡例の上端から下端まで) を、本体の縦の中央に置く。余りが塊の上と下に
  半分ずつ付く (= 塊の中の間隔は変わらない)。題・条件の帯・結論の帯・出所は動かない。余りが無い頁 (= 図が
  本体を使い切る頁) は動かない。資料全体のほか、使い方ごとにも選べる (= 下の `[theme.uses.<名前>]`)
- **`card_look = "outlined"`** は、色を運ぶカード (= `tone` が `accent` / `good` / `bad` と、濃い色の
  `[theme.grounds]`) の地を、その色をごく薄く紙に混ぜた色にし、**色は枠と見出しの字が持つ**。本文の字は
  本文の色。意味を持たない薄い地 (= `box` / `band` / `tint`、薄い色の `[theme.grounds]`) は、もともと
  ほぼ白に枠なので変わらない。`tentative` のカードは本文の色の枠と見出しで、点線にはしない (= 色が「未定」を
  言う)。`strong` は枠を太くする。角は丸くなる。**字は箱の縦の中央に置かれる** (= 上の「カードの字の置き方」)。
  流れ図・道のり・組み立てのカードも同じ
- **`bar_look = "outlined"`** は、線表の棒を `card_look = "outlined"` のカードと同じ決まりで塗る (= 色の役が同じなら、
  カードと棒が同じ色で言う)。色を運ぶ `tone` (= `accent` / `good` / `bad` と、濃い色の `[theme.grounds]`、
  レーンの `tone` も同じ) の棒は、地をその色をごく薄く紙に混ぜた色にし、**色は枠が持つ**。字は本文の色。
  薄い地 (= `box` / `band` / `tint`) の棒は変わらない。`tentative` の棒は本文の色の枠と字で、点線にはしない。
  `strong` は枠を太くする。カードと違い、角は丸くならない。`card_look` とは別に選べる (= 資料のカードだけ、
  棒だけを `outlined` にできる)。カードと棒に同じ色の役を使う資料で、見た目を揃えたい時に選ぶ
- **`band_look = "outlined"`** は、条件の帯を差し色の枠・差し色のごく薄い地・差し色の太字に、結論の帯を
  灰の枠・灰のごく薄い地・本文の色の太字 (= 本文の大きさ) にする。上は頁が置く前提、下は持ち帰らせる言葉を、
  色で見分けられる。帯の高さと位置は変わらない (= 条件の帯の字は `[theme.type]` の `band`)
- **`caption_look = "label"`** は、絵の下の名 (= `caption`。`figure` / `figures` / `figure_grid` / `compose` の
  マスの絵のどれも) を、**本文の色の太字** (= `compose` の `role = "label"` と同じ大きさ) にする。名が絵が何か
  (= どの手法の結果か、入力か正解か) を言う資料に使う。灰の小さい字は出所と同じ見た目で、読み飛ばされる。
  名は今までどおり絵のすぐ下に付き、名の行の高さはその字の大きさと太さで数える

- **`table_look = "plain"`** は、表の見出しの行を**灰の地 (= `wash`) に本文の色の太字**にし、本文の行は
  縞をつけずに紙の色のまま、**どのセルにも灰の罫線 (= `rule`) を引く**。`"accent"` (= 既定) は、見出しの行が
  差し色の地に紙の色の太字、本文は 1 行おきに薄く敷き、罫線は引かない。`shade` で塗ったセルと、区切りの行
  (= 下の「表を区切る行」) は、どちらの見た目でも書ける。表の地の色は `[theme.palette]` の `wash` と `rule` で
  変える

⚠ **枠と見出しの字を色で持つので、差し色・読みの色が薄いと、見出しが地に溶ける** (= 読みやすさの検査
`contrast` が言う)。検査が言う色は `[theme.palette]` で濃くする。

文字の大きさは**資料の使い方**から決まる。映す資料は離れた席から読むので全部が大きく、**載る量はそのぶん減る**
(= 要点だけを載せる)。**紙 1 枚で読ませる頁** (= `sheet`。企画書の 1 枚、詳細を詰めた 1 枚) は近くから読むので
全部が小さく、**余白と間隔も同じ比で詰まる**。この file の他の節に書いてある大きさ (= 12pt / 14pt / 16pt …) は
`read` のもの。

| 役 | どこに使うか | `read` | `present` | `sheet` |
|---|---|---|---|---|
| `title` | 題 | 24 | 32 | 18 |
| `heading` | カード・ノードの見出し | 16 | 24 | 12 |
| `band` | 条件と結論の帯の字 (= 書かなければ `heading`。`band_look = "outlined"` の結論の帯だけは `body`)。**帯の高さはこの大きさから決まる** | 16 | 24 | 12 |
| `display` | `role = "display"` の特大の数字 (= 書かなければ `title` の 2 倍) | 48 | 64 | 36 |
| `tag` | 札 (= `tag = true` のカード) の字 (= 書かなければ `heading`)。**札の高さはこの大きさから決まる** | 16 | 24 | 12 |
| `stage` | 段の名前、レーンの名前、道のりの矢羽根 | 14 | 20 | 10 |
| `body` | 本文、表、要点、読み方 | 12 | 18 | 9 |
| `kicker` | 題の上の小さい字 (= 書かなければ `caption`。`kicker = "beside"` の資料では `title`)。**上に置く時は、題の上の段の高さがこの大きさから決まる** | 10 | 14 | 8 |
| `caption` | 出所、絵の下の説明 | 10 | 14 | 8 |
| (線表の字) | `stage` と `body` の 2 つ (= 収まる大きい方) | 14 か 12 | 20 か 18 | 10 か 9 |
| (段の間の →) | 使い方が決める | 28 | 36 | 21 |
| **下限** | これより小さい字は置けない | 10 | 14 | 8 |
| **余白と間隔** | 箱の内側、物どうしの間、表のセルの内側 | 1 倍 | 1 倍 | 0.75 倍 |

同じ形の頁 (= 3 列の箱、見出しと本文 1 行) に載る箱は、`present` で 12 枚、`read` で 15 枚、`sheet` で 21 枚。

- **`[theme.type]` で上書きできるのは上の 9 つの役** (= `title` / `heading` / `stage` / `body` / `caption` /
  `band` / `display` / `tag` / `kicker`)。下限より小さい値は拒まれる。掛かるのは案件が選んだ使い方 (= `[theme] use`) の大きさだけ
  (= `kicker` だけは、名前を付けた使い方のうち自分で書いていない物にも届く)。
  **見出しだけを小さくしても、帯は小さくならない書き方ができる** (= `heading = 10.5` と `band = 16`。`band` を書かなければ
  帯は見出しに付いて行く)。**札も同じ** (= `heading = 10.5` と `tag = 14`。札はカードの見出しより大きく置く頁がある)
- **大きさを書けるのは `workspace.toml` だけ** ― 資料と頁が選べるのは使い方の名前で、大きさそのものは
  書けない (= 下の「資料ごと・頁ごとに使い方を選ぶ」)。箱ごとには変えられない
- 題の帯・条件と結論の帯・出所の帯の高さは、そこに置く字の大きさに付いて行く。余白と間隔は `read` と
  `present` では同じ値で、`sheet` だけ字と同じ比で詰まる (= 頁の縁の余白と線の太さは、どの使い方でも同じ)
- ⚠ **`read` で収まっていた頁が `present` で収まるとは限らない** ― 収まらない頁は縮めずに止まる
  (= 中身を減らすか、2 頁に分ける)。題も 1 行に入る字数が減る (= 全角で 36 字 → 27 字)
- **検査の文字の下限も使い方に揃う** (= `present` は 14pt)。`read` の大きさで作った頁を複製・輸入すると
  当たる。案件で下げるなら `[checks] type_floor = 10`

### 資料ごと・頁ごとに使い方を選ぶ (= `use`)

映して話す資料の途中に、**情報を詰めた 1 枚** (= 手元で読ませる大きさの頁) を挟める。本編は映す大きさ、
付録や詳細の資料は読ませる大きさ、という分け方もできる。選ぶのは**使い方の名前**:

```toml
# workspace.toml ― 案件の使い方 (= どの資料にも掛かる既定)
[theme]
use = "present"
```

```toml
# 付録.toml ― この資料だけ別の使い方 (= 書かなければ案件のもの)
specimen = "specimen.pptx"
out = "付録.pptx"
use = "read"
```

```toml
# 本編.toml の中の 1 枚 ― この頁だけ別の使い方 (= 書かなければ資料のもの)
[[pages]]
kind = "declare"
type = "table"
use = "read"
title = "…"
```

- **内側が勝つ** ― 頁の `use` → 資料の `use` → 案件の `[theme] use` → `"read"`
- 変わるのは**字の大きさと、それに付いて行く帯の高さ、使い方が選んだ箱の高さ**だけ。書体・色・余白・題の上の
  小さい字の置き場は資料のまま
- **頁に書けるのは名前だけ** (= `body = 10` のように大きさは書けない)。名前で選ぶので、同じ使い方の頁どうしは
  どの資料でも同じ大きさで揃う
- 型で組む頁だけが読む (= 複製と輸入の頁は字を組み直さないので、`use` を書くと拒まれる)
- **検査の下限は、その頁の使い方のもの** (= 映す資料に挟んだ `read` の頁は 10pt。ほかの頁は 14pt のまま)。
  `[checks] type_floor` を書いた案件では、どの頁もその値
- 題の行もその頁の題の大きさで数える (= 映す大きさで 3 行になる題が、`read` の頁では 2 行)

**案件の使い方に名前を付けて足す** (= 大きさを管理する所はここ 1 か所):

```toml
# workspace.toml
[theme.uses.detail]    # 名前は案件が決める (= 資料と頁は use = "detail" で選ぶ)
like = "read"          # 道具の使い方のどれに倣うか (= 必須。"read" か "present")
heading = 14           # そこから変える役だけ書く (= 役は [theme.type] と同じ 8 つ)
body = 11
```

- 下限は**倣った先のもの** (= `read` に倣えば 10pt、`present` に倣えば 14pt、`sheet` に倣えば 8pt。それより
  小さい値は拒まれる)
- `read` / `present` / `sheet` は道具の名前なので、ここでは使えない (= その大きさを変えるのは、案件の `use` に
  選んだ上での `[theme.type]`)
- 案件の `[theme] use` に、ここで付けた名前を書いてもよい
- **箱の高さも使い方ごとに選べる** ― `box_height = "page"` / `"middle"` / `"text"` (= 値は `[theme]` の
  `box_height` と同じ)。書かない使い方は資料の `[theme] box_height` のまま (= 書いた使い方の頁のあとで、
  書かない使い方を名指した頁は、資料の値に戻る)

```toml
[theme.uses.centred]
like = "read"
box_height = "middle"  # この使い方の頁だけ、本体を縦の中央に置く
```

- **表の見た目も使い方ごとに選べる** ― `table_look = "accent"` / `"plain"` (= 値は `[theme]` の `table_look` と
  同じ)。書かない使い方は資料の `[theme] table_look` のまま。青の見出しの資料の中に、灰の見出しの表の頁を置ける。
  表を区切る行 (= `{ band = "…" }`) の塗り方も、その頁の使い方の見た目に従う

```toml
[theme.uses.grey]
like = "read"
table_look = "plain"   # この使い方の頁だけ、表の見出しの行が灰の地・罫線が灰
```

**下限と、余白・間隔も、名前を付けた使い方の中でだけ動かせる**:

```toml
[theme.uses.proposal]
like = "sheet"
floor = 7              # この使い方の字の下限 (= pt。書かなければ倣った先のもの)
body = 8
caption = 7

[theme.uses.proposal.spacing]
scale = 0.6            # 余白と間隔を、read の値の何倍にするか (= まとめて。書かなければ倣った先のもの)
pad = 0.15             # 1 つずつ決める距離 (= cm。書いた物は scale より勝つ)
gap_m = 0.3
```

| `spacing` のキー | 何の距離か | `read` の値 (cm) |
|---|---|---|
| `scale` | 下の距離 (縁の 3 つを除く) と、印・アイコン・矢羽根の尖りをまとめて何倍にするか | 1 |
| `pad` | 箱 (= カード・ノード・帯) の内側の余白 | 0.35 |
| `gap_s` / `gap_m` / `gap_l` | 物どうしの間 (= 小: 見出しと本文、中: 箱と箱・段と段、大: 本体と添え物) | 0.3 / 0.6 / 1.0 |
| `gap_x` / `gap_y` | `compose` の、同じ段のマスとマスの間 / 段と段の間 (= 入れ物の中の段とマスも)。`gap_m` だけ書けば両方がそれに従う | 0.6 / 0.6 (= `gap_m`) |
| `band_gap` | 題・条件の帯・結論の帯・足元の帯と、本体のあいだ。物どうしの間を詰めても帯の下は詰めない時に書く。`gap_m` だけ書けばそれに従う | 0.6 (= `gap_m`) |
| `title_gap` | 題の帯と、その下 (= 条件の帯か本体) のあいだだけ。題と条件の帯の間は広く、条件の帯と本体の間は詰める時に書く。`band_gap` だけ書けばそれに従う。**題の下に線が在れば線から数える** (= レイアウトが題の枠の下に引く線も) | 0.6 (= `band_gap`) |
| `figure_floor` | 高さで詰められた絵の最小の背。これより低くなる頁は止まる。小さくても読める線画 (= 印・記号) を置く頁でだけ下げる | 1.2 (= アイコンの一辺) |
| `cell_pad_y` / `cell_pad_x` | 表のセルの内側 (= 上下 / 左右) | 0.08 / 0.18 |
| `text_inset` | 文字の枠の左右の余白 | 0.25 |
| `row_gap` | 線表の行と行の間 | 0.15 |
| `bar_pad_y` / `bar_pad_x` / `bar_gap` | 線表の棒の内側 (= 上下 / 左右) と、棒どうしの間 | 0.12 / 0.15 / 0.05 |
| `margin_x` / `margin_top` / `margin_bottom` | 頁の縁の余白 (= `scale` は掛からない。書いた時だけ動く) | 1.2 / 0.9 / 0.9 |
| `band_height` / `conclusion_height` | 条件の帯 (= 題の下) と結論の帯 (= 足元の上) の高さ。書いた値のまま置かれ、帯の字の大きさには比例しない | 1.1 (= 字 16pt の時。字に比例する) |

- `floor` を下げた使い方の頁は、検査の下限もその値になる (= ほかの頁は動かない)。上げることもでき、その時は
  書かずに残した役の大きさも新しい下限を上回っている必要がある
- **帯の高さは、書かなければ帯の字の大きさに比例する** (= `band` の字 16pt で 1.1cm)。`band_height` を書くと
  条件の帯がその高さになり、`conclusion_height` を書くと結論の帯がその高さになる。`conclusion_height` だけ
  書かなければ、条件の帯と同じ高さ (= 書いた `band_height`、書かなければ字から割った高さ)。上の帯と下の帯で
  字の大きさが違う資料は、2 つを別に書く
- **帯の高さは 1 行の文の高さ**で、文が折れれば行ぶん伸びる (= 題の帯と同じ。伸びたぶん本体が狭くなる)。
  帯は頁が前提にする読みと持ち帰る言葉なので、1 行で言える長さが目安
- 題の帯と出所の帯の高さは、ここでは書けない (= その帯に置く字の大きさに付いて行く)。線の太さも書けない

**使い方の選び方**:

- **基本は 1 つで通す** ― 案件の `[theme] use` 1 つで、資料のどの頁も同じ大きさと余白で揃える。ふつうの資料は
  これだけで足りる
- **別の使い方を選ぶのは、特殊な頁やデザインを書く時だけ** ― 紙 1 枚で読ませる企画書の頁 (= `sheet`)、映す資料に
  挟む詳細の 1 枚、案件に固有の体裁の頁。道具の使い方で足りなければ、名前を付けた使い方を `workspace.toml` に
  足して、その頁から名前で選ぶ
- 下限や余白を動かした頁は、焼いた絵で見てから出す (= 道具は幅を持たせてあり、読めるかどうかは絵でしか分からない)

### 意味の名前を付けた地 (= `[theme.grounds]`)

色で担当や状態を分ける案件は、地の色に**意味の名前**を付けて宣言する:

```toml
[theme.grounds]
"内部向け" = "EAF0F8"     # 日本語の名前は引用符で囲む (= TOML の決まり)
"外部向け" = "FFF4E5"
"共通" = "E8F3EA"
"遅れ" = "8B1E3F"
```

- 頁では `tone = "内部向け"` と書く (= カード・ノード・レーン・`compose` のカード、どこでも)。道具の色の役
  (= `box` / `band` / `tint` / `accent` / `good` / `bad`) もそのまま書ける。同じ名前は宣言できない
- **字の色は地から決まる** ― 本文の色と紙の色のうち、地との差がはっきりする方 (= 濃い地なら紙の色)。
  本文の色の字が乗る薄い地には、地を濃くした色の枠が付く
- **凡例は自動で出る** ― 宣言した名前を使った頁には、本体の真下 (= 表と読み方の上) に色見本と名前が並ぶ。
  並びは宣言の順で、どの頁でも同じ。使っていない名前は出ない。消すのはその頁に `legend = false`
- **使った名前が 1 つだけの頁には、凡例は出ない** (= 何も見分けていない)。1 つでも出したい頁は `legend = true`
- **凡例を図の中に置く** ― `compose` のマスに `legend = true` と書くと、その頁で使った地の名前の凡例 (= 頁の下の凡例と同じ中身
  と並び) を、**そのマスの中に縦に並べて**描く (= 図の左上の空いたマスなど)。そのマスを持つ頁は、頁の下の凡例を出さない。
  1 つの頁に 1 つまで。名前を使っていない頁、マスが色の名前の幅に足りない時、濃い地の入れ物の中は止まる
- **名前を宣言した案件では、カードに `tone` を書く** ― 書かないカードは道具の既定の薄い地 (= `box`) になり、
  案件が名付けた地と見分けがつかないことがある。検査 `untoned_cards` が知らせる (= 下の「検査」)
- ⚠ **同じ担当は全部の頁で同じ名前で書く** (= 色を頁ごとに選ばない。色は宣言の 1 か所で決まる)
- 使える名前は `task types` の `tone` の行に出る

## 検査

`build` は最後に 17 個を回す。当たりが 1 つでも在れば `build` は失敗で終わる。

焼いた deck を読み直す検査 (= `check` でも回る):
頁の外 / **重なり** / 文字の下限 / 表の空セル / 内部 file 名 / テンプレートの語の残り /
**使わない語の残り** (`avoided_words`) /
種類の登録が無い部品 (= 開けない pptx の種) / **題が 3 行以上** (`long_title`、複製・輸入の頁) /
**地に溶ける字** (`contrast`) / **潰れた絵** (`stretched`) / **ぼやける絵** (`low_resolution`) /
**揃え損ね** (`near_alignment`)

manifest を読む検査 (= `build` だけが回す):
**題が 3 行以上** (`long_title`、宣言で組む頁) / **出所の無いデータの頁** (`unsourced`) /
**値の軸の名前が無いグラフ** (`unnamed_axis`) / **中の段ごとの目次の無い長い章** (`section_agenda`) /
**`tone` の無いカード** (`untoned_cards`、地に名前を付けた案件だけ)

**検査の報告が言う「page N」は、ファイルの並びの N 番目** (= manifest の `[[pages]]` の N 番目と同じ)。
表紙に番号を付けない資料は数え始めが 0 なので、人とプレビューが言う番号とずれる。そういう資料の報告は
`page 3 (printed 2)` のように、刷られる番号を添える (= 数え方は PowerPoint と同じ。隠した頁も数に入れる)。
人と頁の話をする時は、`printed` の番号で言う。`build` の最初の行 (`built … (N pages; …)`) も、数え始めが
1 でない資料は、それを言う。`task titles` (= 焼いた後) と `review` の差分・取り込みの報告も同じ言い方をする。
組んでいる途中で止まった `build` の失敗は、刷られる番号がまだ決まらないので `page 2 of the manifest: …`
(= manifest の 2 番目の `[[pages]]`) と言う。

- `avoided_words` ― 案件が `[checks.avoid]` に「使わない語 = 代わりの語」 で書いた語が、頁の字かグラフの中に
  残っていれば、頁の番号と代わりの語を知らせる (= 書き手が自作した訳語は、読み手が意味を読めない。作法 `craft.md`
  の「語は、読み手の物を使う」 を、語の表で止める)。頁の字は段落ごとに run をつないで読むので、太字の境で割れた
  語も当たる。グラフは題・軸の名前・項目名・系列名を読む。**絵 (= 画像) の中の字と、グラフの下に付く表データは読まない**。
  大文字小文字は書いた通りに区別し、部分一致なので短い語は長い語の中でも当たる。知らせるのは 1 頁 1 語につき 1 行
- `long_title` ― 題は 2 行まで。3 行に達した題を知らせる (= 短く言い直す)
- `untoned_cards` ― 案件が `[theme.grounds]` で地に名前を付けている時、宣言で組む頁の `tone` の無いカード
  (= `cards` の並びと、`compose` のマスや入れ物の中の `card`) を、頁ごとに数えて知らせる。`["見出し", "本文"]`
  の書き方は `tone` を持てないので当たる (= 表の書き方にして `tone` を書く)。名前を宣言していない案件では見ない
- `unsourced` ― 宣言で組む頁が絵・表・グラフを持つのに `footer` が空なら知らせる (= どこから来たかを `footer` に
  書く)。流れ図・道のり・線表とカードだけの頁は対象外
- `unnamed_axis` ― 宣言で組む頁の項目のグラフ (= `bar` / `column` / `line` / `stacked` / `waterfall`。`compose` の
  マスの中も) が値の軸の名前を持たなければ知らせる (= 縦のグラフは `y`、横棒は `x` に単位も含めて書く)。
  `bare` の棒と点の列は値の軸を持たないので対象外
- `section_agenda` ― 章の頁 (= 目次を除く) が 6 を超え、中の段 (= 目次の小項目) が 2 つ以上あるのに、中の段の頭
  ごとの目次 (= 同じ章を `highlight` し、その段を `highlight_item` で強調した `look = "cards"` の目次) が揃って
  いなければ、章の頭の目次の頁で知らせる (= まだ無い段の番号も)。章の範囲は、章を `highlight` した目次から、別の章を
  名指す目次の手前まで。長さは `[checks] section_agenda` で変えられる

- `contrast` ― 字の色と地の色の明暗差が、普通の字で 4.5、大きい字 (= 18pt 以上、太字は 14pt 以上) で 3 に
  届かない字を知らせる (= Web の読みやすさの基準 WCAG 2 の AA)。地は字の図形の塗り → 下に敷かれた図形の
  塗り → 頁の背景の順に探す。字の色を書いていない字と、グラデーション・絵の上の字は測らない。テンプレートの
  ブランドの色の組 (= 差し色の地に白い字) のように動かせない組は、`[checks] contrast_allowed` に字の色と
  地の色の組で書くと通る (= 下の例)。通した組は報告に `pass` の行で、何か所・どの頁かと一緒に出る。
  型で組んだ字も、この組なら色を寄せずに置く (= 向きが逆の組は寄せる)。
  テンプレートの folder の `workspace.toml` に書けば、そのテンプレートから建てる案件に最初から入る
- `stretched` ― 元の縦横比 (= 切り抜いた絵は残った部分の比) から 2% を超えて潰れた・伸びた絵を知らせる
  (= 枠の角を片側だけ引いた絵。比を戻すか、切り抜く)
- `low_resolution` ― 頁の上で 1 インチに 150 画素を割る絵を知らせる (= 映すとぼやける。大きい絵にするか、
  小さく置く)
- `near_alignment` ― 揃うはずの組 (= 同じ高さで横に並ぶ箱の上端、同じ幅で縦に積む箱の左端) が、揃わずに
  1 mm 未満だけずれていれば知らせる (= 1 mm 以上はわざとずらした物とみなす)
- 新しい 4 つが当たるのは、ほぼ複製と輸入の頁 (= 宣言で組む頁は、地に合わせて字の色を選び、絵の比を保ち、
  同じ枠から割って揃える)。`low_resolution` だけは宣言の頁でも、渡した絵が小さければ当たる

`stale_words` と `[checks.avoid]` は案件の `workspace.toml` に書く。検査は案件ごとに外せ、文字の下限は案件で
決められる:

```toml
[checks]
stale_words = ["案件名", "第 N 回"]
unsourced = false       # 出所の検査を外す (= 絵が図解ばかりで、出所を書く物が無い案件)
unnamed_axis = false    # 値の軸の名前の検査を外す
section_agenda = 8      # 中の段ごとに目次が要る章の長さ (= 目次を除く頁の数。書かなければ 6。false で外す)
untoned_cards = false   # tone の無いカードの検査を外す
long_title = false      # 題の長さの検査を外す
type_floor = 10         # 文字の下限 (= 書かなければ資料の使い方の下限。read は 10、present は 14)
contrast = false        # 字と地の明暗差の検査を外す
contrast_allowed = [    # 明暗差の検査で通す、字の色と地の色の組 (= 16 進 6 桁。検査は残したまま、この組だけ通す)
  { words = "FFFFFF", ground = "2E9E5B" },   # 差し色の地に白い字
  { words = "2E9E5B", ground = "FFFFFF" },   # 白い地に差し色の字
]
stretched = false       # 絵の潰れの検査を外す
low_resolution = false  # 絵の粗さの検査を外す
near_alignment = false  # 揃え損ねの検査を外す

[checks.avoid]          # 使わない語 = 代わりの語 (= 頁の字にもグラフにも残っていれば build が止まる)
"二重の殻" = "ラッパー"
"鏡の写し" = ""         # 代わりの語を決めていない語は "" (= 報告に代わりの語を出さない)
"手順書" = false       # テンプレートが書いた語を、この案件では外す (= false の語は検査しない)
```

`[checks.avoid]` はテンプレートの folder の `workspace.toml` にも書ける。テンプレートと案件の両方に書くと
鍵 (= 使わない語) ごとに重なり、同じ語は案件の代わりの語が勝つ。案件は `false` でテンプレートの語を外せる。

## 絵の枠を読む

```bash
task frames -- w1
```

宣言で組む頁の絵ごとに、道具が絵に渡す枠の大きさと、実際に置かれる大きさを JSON で出す。絵は縦横比を
保って枠の中に置かれるので、**グラフを枠と同じ大きさで描けば、絵は枠いっぱいに置かれ、描いた字の大きさが
そのまま頁に載る** (= 例: matplotlib なら `figsize` に枠の `width_in` と `height_in` を渡す)。枠より縦長・横長に
描いた絵は縮められて字が小さくなり、隙間の分だけ揃え損ね (`near_alignment`) に掛かることもある。

```json
[{"page": 3, "picture": "w1-chart.png",
  "frame":  {"width_emu": 5486400, "height_emu": 3200400, "width_in": 6.0, "height_in": 3.5},
  "placed": {"width_emu": 5486400, "height_emu": 3086100, "width_in": 6.0, "height_in": 3.375}}]
```

- 焼かずに build と同じ道で頁を組んで読むので、`out` の deck には触らない
- `frame` は絵の名 (`caption`) の行を除いた残り。`placed` は今の絵の縦横比で置いた大きさ
- 同じ絵を 2 頁に置けば、頁ごとに 1 件ずつ出る。複製・輸入の頁の絵は出ない (= テンプレートの絵の枠に差し替わる)
- 段の高さを絵の縦横比で割り振る頁では、描き直して縦横比が変わると枠も動く。描き直した後にもう一度読む
- 枠ぴったりに描けない時は、**枠より少し低く描く** (= 幅で決まる側に外す)。枠より少しでも縦に長い絵は高さで
  縮められ、幅が足りない分 (= 1 mm 未満) が揃え損ね (`near_alignment`) に掛かる

## 題を順に読む

```bash
task titles -- w1
```

頁の番号と題 (= 題の上の小さい字が在ればそれも) を 1 行ずつ出す。**題だけを順に読んで話が通るか**を
見るための口 ― 頁を 1 枚ずつ直していると、並びとしての話は見えなくなる。宣言で組む頁は manifest から、
複製・輸入の頁は焼いた deck から読む (= 先に `build` しておく)。
