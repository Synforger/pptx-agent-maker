# <project>

デッキ 1 案件の置き場。**ツールはここに入らない** (= ツールは `pptx-agent-maker`、ここは案件の
ものだけ)。ツールがこの folder を見つける口は `workspace.toml` 1 枚。

```
<project>/
├── workspace.toml     この設定 (= 予約名)
├── specimen.pptx      見た目の元 (= 予約名。この上に頁が書き足される。プロジェクトテンプレートが 1 枚持っている)
├── w1.toml            ← 何を並べるか
├── w1.pptx            ← それを焼いたもの
├── w2.toml
├── w2.pptx
└── assets/
    ├── w1/            マニフェストと同じ名前の folder が、その回の素材
    └── w2/
```

**焼いたデッキと、それを組んだマニフェストが対で並ぶ。**開いて確かめるのは焼いたほうなので、
それがマニフェストの隣に在るのがいちばん短い。回を folder で仕切ると、1 回ぶんを見るのに
2 階層降りることになる。素材だけは数が多いので回ごとに分ける。

## 始め方

```bash
pptx-agent-maker init <案件のフォルダ> --specimen <テンプレート.pptx or テンプレートを置いた folder>
cd <案件のフォルダ> && task build -- example
```

`--specimen` を書かなければ、ツールの既定の見た目で建つ (= あとで差し替えてもよい)。
⚠ **建てる 1 手で決めるほうが安全** ― あとから手で上書きする形だと、上書きし忘れた回だけ
顔が変わる。

folder を渡すと `specimen.pptx` と、その隣の `workspace.toml` を一緒に持ってくる。
⚠ **色の表が要るのはこのため** ― pptx のテーマ色は「1 番目の差し色」という枠でしかなく、
ツールは「読みを示す色」「条件の帯」という**意味**で色を使う。その 2 つを繋ぐ表はテンプレートの
中に書けないので、対で置く。

**写した直後に 1 本焼ける。**同梱の `example.toml` と、それが要るテンプレートと絵が入っている。

以降はこの folder の中だけで済む (= `Taskfile.yml` がツールへの口を持つ)。

| | |
|---|---|
| `task build -- w1` | `w1.toml` からデッキを組んで検査する |
| `task check -- w1.pptx` | 焼いたものを読み直す |
| `task review -- w1.pptx` | 人が直した所を部品単位で出す |
| `task preview` | 焼いたものをブラウザで追う |
| `task show` | この案件が何をどこに置いているか |

**ツールはこの folder に入らない。**1 つの機械に 1 度入れて、案件はいくつでもそれを呼ぶ
(= `pipx install <ツールの checkout>`)。入っていなければ task がその旨だけ言って止まる。

## 見た目はテンプレートが持つ

同梱の `specimen.pptx` は**ツールの既定の見た目**で焼いた見本 (= どこの会社のものでもない)。
案件の見た目にするときは、**この 1 枚を差し替えるだけ**でよい ― 複製する頁も、型で組んだ頁も、
PowerPoint で開いて手で足した頁も、全部そこから見た目を取る。

`workspace.toml` の `[theme]` は**その上に重ねる例外**で、テンプレートの配色がツールの色の使い方
(= 読みを示す色 / 条件の帯) と合わないときだけ書く。書いた色だけが上書きされ、
残りはテンプレートのまま。

頁の割り方 (= 余白・級数・間隔) は案件から動かせない。同じ役割の頁が回をまたいで
同じ形であることのほうを取る。

## 決まり

- **ツール側に案件の語を持ち込まない。**使える部品 (= 帯・カード・図・表) はツールが持ち、
  何をどう並べるかはここが持つ
- **`*.pptx` は焼き直せるもの**。消えて困るものを置かない (= `specimen.pptx` だけが別)
- **ツールの見本を案件の見た目で上書きしてよい** (= プロジェクトテンプレートが持つのは出発点であって、正解ではない)
- **回の名前がそのまま素材の folder 名** (= w1 のマニフェストは assets の下の w1 を見る)。
  マニフェストに `assets` と書けば変えられる
