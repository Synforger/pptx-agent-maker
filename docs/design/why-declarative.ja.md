# なぜ座標を書かせないか

## 測った事実

長く続いた連載デッキを後から数えると、**頁のかなりの割合が「その回だけの自作図解頁」**で、型を
持たない層だった。そこに書かれた script の**相当数は、一度も焼かれていない**。

同じ役割を回ごとに作り直した例がいくつもあり、極端なものは script が何本にも増えていた。
隣り合う回の類似度は**丸ごとの複製から始まり、やがて別物と言える所まで落ちる**。
**前半は完全な複製を型にしないまま繰り返し、後半は書き直して別物にした。**

## そこから決めたこと

1. **座標を受け取る口を作らない。** 版面を割ることしかできなければ、枠外れも重なりも起きない。
   検査で探す形は、1 行ぶんの飛び出しを通した実績がある
2. **寸法・色・文字は 1 枚の表が持つ。** 頁が自分で決めると、書くたびに 2pt ずれて灰色が 3 種類になる
3. **同じ宣言は同じ座標を返す。** 週をまたいだ比較は「型が同じ」ことでしか成り立たない
4. **規律で守れなかったものは組めなくする。** 図解の無い頁 / 空セル / 下限を割る文字 /
   枠に入らない表。どれも「気をつける」では守れなかった

## 宣言層でも解けないもの

- **文字が折り返して伸びる高さ**。表の行数は先に測れるが、長い文が何行になるかは焼くまで分からない。
  → 焼いた後に頁外れを測る検査が別に要る (= 宣言層と後段の検査は役割が違う)
- **読みやすさ**。座標が正しくても、どれを見ればよいかは人が決める。だから焼いて目で見る工程は消えない
